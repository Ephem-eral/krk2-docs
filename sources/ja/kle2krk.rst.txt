KLE から KRK へ
================

Keyboard Layout Editor はオブジェクトに名前を付けませんが、Blender と Keyboard Render Kit が正しく動作するには名前が欠かせません。Blender ではオブジェクトとオブジェクトデータが別々に命名されます。Keyboard Render Kit は基本的にオブジェクト名を参照せず、オブジェクトデータ名に大きく依存して動作します。これを押さえておけば、KLE から KRK への変換はかなり確実に行えます。

|

KRK に変換できるのは何か？ コンバーターが処理するのは、サイズ、レジェンド、行（row）、色（キーキャップの色とレジェンドの色）、位置、回転です。後ろの3つは自由に変更できますが、最初の3つを変更したうえで対応するターゲットのオブジェクトデータが存在しない場合、キーキャップがインポートされないことがあります。

|

`Keyboard Layout Editor の例 <http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a>`_

|

このレイアウトは KLE から KRK への変換のテスト基準であり、問題なく KRK に読み込めるため、優れた参考サンプルです。まだ自分のレイアウトを作り始めていないなら、ここから始めるのがおすすめです。どこかで見覚えがあるかもしれません——KRK のキーキャップの UV とテクスチャにはこのレイアウトが使われています。

|

.. image:: img/KLEKRK2.jpg

|

レジェンドと行の命名に注意してください。変換時に実際に機能するのはこれらであり、変更するとまったく変換できなくなる可能性があります。レジェンド自体は変換されず、キーキャップの名前としてのみ機能することを覚えておいてください——Blender に入った後は、レジェンドマスクを通じて、キーキャップは任意のレジェンドを表示できます。
