Первый рендер клавиатуры
==============================

Теперь, когда основы освоены, отрендерим целую клавиатуру и закрепим навыки из первого урока.

|

Создайте новый файл KRK2, нажмите A во вьюпорте, чтобы выделить всё, затем нажмите Set в области Relink панели KRK, чтобы задать высоту Cherry.
Перетащите Capsmat из браузера ассетов на один из кейкапов, зажмите Shift и щёлкните по нему, чтобы сделать активным объектом, затем нажмите Copy в области Data панели KRK.

.. image:: img/SetCapsmatCopy.gif

|

Затем нажмите Copy в области Color панели KRK, чтобы сохранить информацию о цвете для дальнейшего использования.

.. image:: img/CopyColors.JPG

|

.. note:: Если вы не планируете выполнять постобработку финального изображения (это не рекомендуется), установите хотя бы схему управления цветом «Standard» или задайте look «Medium High Contrast».

|

Теперь скройте коллекцию Kits с помощью параметров видимости в структуре (Outliner).

.. image:: img/TurnOffKits.gif

|

Перетащите клавиатуру Dalco 959 Mini WKL из браузера ассетов, нажмите Alt+G, чтобы сбросить положение, затем нажмите Restore Collections, чтобы сделать её редактируемой.

.. image:: img/DalcoRestore.gif

На 959 Mini выберите один плейсхолдер, рамкой выделите все плейсхолдеры, затем нажмите Set в области Relink панели KRK.

.. image:: img/BoardPopulate.gif

Нажмите Setup в области Color, затем Paste — так вы восстановите цвета, сохранённые ранее из набора.

|

Теперь соберём сцену.

|

Разверните Lights в коллекции сцены, отключите видимость KitLightingHigh и включите SoftBoxStudio.
В коллекции Floors включите FloorWood6.

.. image:: img/LightsFloor6.jpg

|

В свойствах сцены установите камеру Camera_Board2.

.. image:: img/SetCamera.jpg

|

Поверните вид под подходящим углом, затем нажмите View > Align View > Align Active Camera To View (Ctrl+Alt+Num 0), чтобы совместить активную камеру с текущим видом.

.. image:: img/SetActiveCamera.gif

|

Теперь отрендерьте сцену.

.. image:: img/TutBoardRender.jpg

|

На этом второй пример рабочего процесса завершён.

|
