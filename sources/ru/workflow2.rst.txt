Твой первый рендер клавиатуры
==============================

Основы ты уже освоил, теперь отрендерим целую клавиатуру и заодно расширим то, что узнал в первом уроке.

|

Создай новый файл KRK2, во вьюпорте нажми A, чтобы выделить всё, затем нажми Set в области Relink панели KRK, чтобы задать им высоту Cherry.
Перетащи Capsmat из браузера ассетов на один из кейкапов, зажми Shift и щёлкни по этому кейкапу, чтобы сделать его активным объектом, затем нажми Copy в области Data панели KRK.

.. image:: img/SetCapsmatCopy.gif

|

Затем нажми Copy в области Color панели KRK, чтобы сохранить информацию о цвете для дальнейшего использования.

.. image:: img/CopyColors.JPG

|

.. note:: Если ты не собираешься делать никакой постобработки финального изображения (это не рекомендуется), то хотя бы установи схему управления цветом в "Standard" или задай look "Medium High Contrast".

|

Теперь скрой коллекцию Kits с помощью параметров видимости в структуре (Outliner).

.. image:: img/TurnOffKits.gif

|

Перетащи клавиатуру Dalco 959 Mini WKL из браузера ассетов, нажми Alt+G, чтобы сбросить положение, затем нажми кнопку Restore Collections, чтобы сделать её редактируемой.

.. image:: img/DalcoRestore.gif

На 959 Mini выбери один плейсхолдер, рамкой выдели все плейсхолдеры, затем нажми Set в области Relink панели KRK.

.. image:: img/BoardPopulate.gif

Нажми Setup в области Color, затем Paste — и цвета, сохранённые ранее из набора, вернутся.

|

Теперь соберём сцену.

|

Разверни Lights в коллекции сцены, отключи видимость KitLightingHigh, включи SoftBoxStudio.
В коллекции Floors включи FloorWood6.

.. image:: img/LightsFloor6.jpg

|

В свойствах сцены установи камеру Camera_Board2.

.. image:: img/SetCamera.jpg

|

Поверни вид под удачным углом, затем нажми View > Align View > Align Active Camera To View (Ctrl+Alt+Num 0), чтобы сделать текущий вид активной камерой.

.. image:: img/SetActiveCamera.gif

|

Теперь отрендери свою сцену.

.. image:: img/TutBoardRender.jpg

|

На этом второй пример рабочего процесса завершён.

|
