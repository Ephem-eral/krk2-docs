Панель KRK
============

.. image:: img/krkpanel204.jpg

Панель KRK находится на боковой панели (вызывается клавишей N) и разделена на четыре области: Relink, Data, Color и Properties. Последние две области появляются только тогда, когда доступны соответствующие свойства.

|

Relink (перелинковка)
---------------------

Relink — это менеджер данных объектов, предназначенный для быстрого переключения профиля (высоты) кейкапов, ряда, размера, типа клавиши и клавиши позиционирования (homing). Все опции, у которых установлен флажок, применятся при нажатии Set.

|

Импорт KLE
^^^^^^^^^^

KRK умеет импортировать JSON-файлы Keyboard Layout Editor. KLE не даёт имена объектам, поэтому импортёр определяет клавиши по символам и ряду (K1–K6) и расставляет плейсхолдеры там, где это возможно. Можно использовать этот KLE как пример или взять его за основу для создания собственной раскладки:

`http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a <http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a>`_

|

Profile (высота)
^^^^^^^^^^^^^^^^

.. image:: img/KRK2ProfileSwitch.gif

Доступные высоты и их префиксы находятся в коллекции Profile в структуре (Outliner); ряд и остальные опции осваиваются после нескольких использований. Введите опцию в соответствующее поле (с учётом регистра), установите флажок и нажмите Set для применения.

|

Row (ряд)
^^^^^^^^^

.. image:: img/KRKRows.jpg

Поскольку разные производители и разные профили (высоты) кейкапов используют собственные системы нумерации рядов, KRK вводит свою нумерацию, основанную на фактическом положении на клавиатуре, начиная с самого дальнего ряда.

|

+--------+-------+-------------+-------+
| Высота | Опция | Ряд         | Опция |
+========+=======+=============+=======+
| KRK    | 0     | 1-2-3-4-5-6 | 7     |
+--------+-------+-------------+-------+
| Cherry | 0     | 1-1-2-3-4-4 | 5     |
+--------+-------+-------------+-------+
| DCS    | 5     | 1-1-2-3-4-4 |       |
+--------+-------+-------------+-------+
| DSA    |       | Uniform     |       |
+--------+-------+-------------+-------+
| DSS    |       | 1-1-2-3-4-3 | 4     |
+--------+-------+-------------+-------+
| KAM    |       | Uniform     |       |
+--------+-------+-------------+-------+
| KAT    | 5     | 4-4-3-2-1-1 |       |
+--------+-------+-------------+-------+
| OEM    |       | 1-1-2-3-4-4 |       |
+--------+-------+-------------+-------+
| SA     |       | 1-1-2-3-4-3 | 4     |
+--------+-------+-------------+-------+

У некоторых высот первый и/или последний ряд можно менять местами.

(Uniform в таблице означает, что все ряды одинаковой высоты; вводится как есть.)

|

Size (размер)
^^^^^^^^^^^^^

.. image:: img/KRK2ShiftSize.gif

Введите четырёхзначный размер в единицах (unit size) в поле, чтобы изменить размер кейкапа; если целевая геометрия существует, кейкап примет нужный размер.

|

Key (клавиша)
^^^^^^^^^^^^^

.. image:: img/Releg.jpg

Введите название кейкапа в поле, чтобы заменить кейкап на другой. Особенно удобно для замены на кейкап со сменной легендой (Releg), кейкап без надписей (Blank) или кейкап с окном (``*_WIN``).

|

Homing (клавиши позиционирования)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. image:: img/KRK2Homing.gif

Используйте этот выпадающий список для переключения типа клавиши позиционирования между bar/nub/scoop (перекладина/бугорок/впадина), затем нажмите Set.

|

Link Material (связать материал)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Link Material переносит текущий применённый материал на данные целевого объекта. Включать или выключать его зависит от желаемого результата: например, при переключении на высоту-плейсхолдер (PLA) его следует отключить, чтобы Capsmat не перенёсся на плейсхолдер.

|

Copy Settings (копировать настройки)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. image:: img/CopySettings.jpg

Справа от кнопки Set находится Copy Settings — она копирует имя данных объекта в выпадающий список данных объекта, что упрощает поиск конкретной клавиши.

|

   Следующие области отображают только опции, соответствующие текущему активному (выделенному) объекту.

|

Data (данные)
-------------

Data переносит назначение данных объекта и материалов из панели свойств для более удобного доступа.

|

Здесь можно быстро искать данные объекта и заменять текущие на другие. Например, скопировать или создать экземпляр кейкапа, а затем превратить копию в свитч (переключатель) или стабилизатор.

.. image:: img/ObjectDataSwitch.gif

|

Если кейкап не удаётся перелинковать из-за копирования, импорта или вставки, используйте Restore Meshes, чтобы заново связать его с одноимённой версией в файле. Если вы хотите взять за основу импортированную версию, переименуйте её данные объекта, убрав окончание .001.

.. image:: img/RestoreMesh.gif

|

Restore Collections появляется только при выборе ассета коллекции и служит для восстановления его в редактируемое состояние.

.. image:: img/RestoreCollection.jpg

|

Copy здесь связывает материал с текущего активного кейкапа со всеми остальными выбранными кейкапами, игнорируя объекты, не являющиеся кейкапами.

.. image:: img/MatCopy.gif

|

Color (цвет)
------------

Color — это система управления цветом и палитрой, помогающая контролировать связанные с цветом свойства Capsmat; отображается только тогда, когда доступны свойства цвета.
Если у выбранного кейкапа нет свойств цвета, появится кнопка Setup для добавления всех необходимых свойств этому кейкапу.

.. image:: img/ColorSetup.jpg

|

Переключатель Custom/Palette позволяет выбирать между рабочими процессами пользовательских цветов и палитры. Цвета A–E и ползунки палитры A–E через группу узлов палитры позволяют управлять этими частями Capsmat для каждого объекта отдельно. После выбора нажатие Set применит их ко всем выбранным кейкапам; также можно нажать отдельные кнопки копирования, чтобы скопировать только один пункт за раз. Кнопки Copy и Paste внизу служат для создания и вызова записи настроек для всех выбранных объектов.

.. image:: img/ColorSetPaste.gif

|

Properties (свойства)
---------------------

Properties также отображается только тогда, когда доступны пользовательские свойства: при выборе кабеля USB отображаются опции кабеля, например оплётка/TechFlex и цвет термоусадки разъёма; при выборе коврика отображаются опции размера и окантовки.

.. image:: img/KRK2PanelProps.gif

|
