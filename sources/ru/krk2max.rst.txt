KRK в 3ds Max
==============

Экспорт в 3D Studio Max довольно прост, но есть несколько моментов, которые стоит учесть заранее: 3ds Max работает с полигонами (N-угольниками) хуже, чем Blender, зато предпочитает треугольники и четырёхугольники — так что дадим ему то, что он хочет.

.. image:: img/krk2maxstart.jpg

|

Когда клавиатура или кит готовы, скройте все остальные объекты, не участвующие в экспорте — обычно это коллекция сцены, отключите её.

.. image:: img/TurnOffSceneCollection.gif

|

Когда видимым останется только он, выберите один из объектов, нажмите A, чтобы выделить всё, затем Tab, чтобы все выделенные объекты вместе перешли в режим редактирования.

.. image:: img/KeyboardVertices.jpg

|

Нужно находиться в режиме выбора граней, горячая клавиша — 3 на цифровой строке.

.. image:: img/FaceMode.jpg

|

Нажмите A дважды подряд (или Alt+A), чтобы снять всё выделение.

.. image:: img/KeyboardFaces.jpg

|

Затем нажмите Select > Select By Trait > Faces By Sides.

.. image:: img/FaceBySides.gif

|

В появившейся панели слева внизу установите тип Greater Than (больше).

.. image:: img/SelectGreaterThan.jpg

|

Теперь все N-угольники (и только они) выделены.

.. image:: img/KeyboardNgons.jpg

|

Затем нажмите Face > Triangulate Faces или Ctrl+T для триангуляции, после чего нажмите Tab, чтобы выйти из режима редактирования.

.. image:: img/KeyboardTriangulate.gif

|

Клавиатура готова к экспорту: нажмите File > Export > FBX, задайте имя файла, установите Path Mode в Copy и не забудьте поставить галочку Limit to Selected Objects (только выделенные объекты).

.. image:: img/krk2maxexportsettings.png

|

Затем импортируйте этот FBX в Max.

.. image:: img/krk2maximported.png

|
