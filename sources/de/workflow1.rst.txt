Ihr erstes Kit-Rendering
=========================

Das Erste, was Ihnen beim Einstieg auffällt, ist, dass keine Keycaps vorhanden sind. Stattdessen sehen Sie viele Flächen im 3D-Viewport. Dabei handelt es sich um Platzhalter, die durch Keycaps ersetzt werden können.

.. image:: img/Placeholders.PNG

|

Wählen Sie die Platzhalter mit einer Rahmenauswahl aus und drücken Sie anschließend die Schaltfläche Set im Bereich Relink des KRK-Panels. Der Relink-Vorgang ignoriert alle Objekte außer den Keycap-Objekten, und Sie sollten nun Keycaps mit Cherry-Profil erhalten. Relink ignoriert außerdem Keycaps ohne Ziel-Objektdaten. Die Profilpräfixe finden Sie in der Sammlung Profile.

.. image:: img/setcherry.gif

|

Ziehen Sie das Capsmat aus dem Asset-Browser auf eines der Keycaps. Mit diesem Keycap als aktivem Objekt (hervorgehoben) können Sie das Material auf die anderen Keycaps übertragen, indem Sie die Schaltfläche Copy im Bereich Data des KRK-Panels drücken. Dies entspricht Ctrl+L und anschließend M (Material verknüpfen), ignoriert jedoch Objekte, die keine Keycaps sind.

.. image:: img/copymat.gif

|

.. note:: Wenn Sie keine Nachbearbeitung Ihres finalen Bildes planen (nicht empfohlen), stellen Sie zumindest das Farbmanagement-Profil auf „Standard“ ein oder setzen Sie den Look auf „Medium High Contrast“.

|

Das Paletten-System ist für die Farbexploration konzipiert. Sie können mit benutzerdefinierten Farben pro Objekt beginnen und später einen strengeren Ansatz mit definierten Paletten im Material-Editor verfolgen.

.. image:: img/CustomPalette.gif

|

Die Paletten sind universelle Node-Gruppen, standardmäßig sind sie jedoch wie folgt belegt:

- **A** Keycap-Farbe
- **B** Farbe der Beschriftung
- **C** Farbe der Zusatzbeschriftung (nicht angewendet)
- **D** Farbe der Frontbeschriftung (nicht angewendet)
- **E** Beschriftungsmasken

.. image:: img/Palettes.PNG

|

Testen Sie die Regler an einem Keycap und wechseln Sie zu Custom, um Ihre eigenen Farben festzulegen. Sobald Ihnen das Ergebnis gefällt, können Sie es auf alle anderen ausgewählten Keycaps übertragen, indem Sie die Schaltfläche Set im Bereich Color drücken, wobei dieses Keycap zuletzt ausgewählt sein muss.

.. image:: img/SetColor.gif

|

   Keycap-Farben können jetzt am Objekt statt nur im Material gespeichert werden. Sie können weiterhin den traditionellen Workflow verwenden, wenn Sie dies bevorzugen, und die Paletten aus dem Material entfernen.

|

Verwenden Sie den Regler für Palette E, um die Beschriftung einer Modifikatortaste zwischen Text, Icon oder Text+Icon umzuschalten.

.. image:: img/PaletteE.gif

|

Fügen Sie einen Boden hinzu, indem Sie die Sichtbarkeitsoptionen für FloorLightGrey im Outliner aktivieren. Er ist als erstes Element unter Scene>Floors zu finden.

.. image:: img/floorvis.gif

|

Klicken Sie auf Render>Render Image oder drücken Sie F12, um Ihr erstes Bild zu rendern.

.. image:: img/w1render.jpg

|

Sie haben gerade das Beispiel-Workflow-Tutorial 1 abgeschlossen.

|

   Bonuspunkte:
   Ändern Sie die Kamera in den Szeneneigenschaften auf Camera_Kit_Tilted.
   
|
