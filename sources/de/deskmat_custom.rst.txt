Hinzufügen Ihrer eigenen Deskmat Design
=======================================

Sie können Ihr eigenes Deskmat-Design zum Deskmat hinzufügen, indem Sie drei Materialien bearbeiten: Deskmat_Mat, Deskmat_Edging und Deskmat_Stitching. Diese finden Sie im Panel Materialeigenschaften.

.. image:: img/Deskmat_Slots.jpg

|

Finden Sie den Bildtexturknoten in jedem der Materialien und laden Sie Ihr eigenes Bild in den Knoten.

.. image:: img/Deskmat_Thoughts.jpg

|

Standardmäßig ist das Deskmat in der Lage, auf 1mx1m zu skalieren, so dass Ihr Design auf einem 1mx1m Quadrat positioniert werden sollte.

.. image:: img/Deskmat_Square.jpg

|

Wenn Sie ein anderes Bild verwenden möchten, stellen Sie sicher, dass die Position im Mapping-Knoten auf die Hälfte der Deskmat-Größe und die Skala auf die Größe in Metern eingestellt wird.

.. figure:: img/Deskmat_Image.jpg

Bild: Milchstraße von Metallbender und dem Raumigen

|

Sie können den Bildtexturknoten auch durch ein Muster ersetzen.
