Ihr erstes Tastatur-Rendering
==============================
Nachdem Sie nun die Grundlagen kennen, wollen wir eine Tastatur rendern. Wir bauen auf dem auf, was wir im ersten Tutorial gelernt haben.

|

Drücken Sie in einer frischen KRK2-Datei im 3D-Viewport A, um alles auszuwählen, und drücken Sie dann im KRK-Panel im Bereich Relink auf die Schaltfläche Set, um alles auf das Cherry-Profil zu setzen.
Ziehen Sie das Capsmat aus dem Asset-Browser auf einen der Keycaps. Klicken Sie bei gedrückter Shift-Taste auf denselben Keycap, um ihn zum aktiven Objekt zu machen, und drücken Sie im KRK-Panel im Bereich Data auf die Schaltfläche Copy.

.. image:: img/SetCapsmatCopy.gif

|

Klicken Sie nun im KRK-Panel im Bereich Color auf Copy. Damit werden die Farbinformationen gespeichert, um sie später wieder abzurufen.

.. image:: img/CopyColors.JPG

|

.. note:: Wenn Sie keine Nachbearbeitung Ihres finalen Bildes planen (nicht empfohlen), setzen Sie zumindest das Farbmanagement-Profil auf „Standard“ oder stellen Sie den Look auf „Medium High Contrast“.

|

Blenden Sie nun die Sammlung Kits über die Sichtbarkeitsoptionen im Outliner aus.

.. image:: img/TurnOffKits.gif

|

Ziehen Sie die Tastatur Dalco 959 Mini WKL aus dem Asset-Browser und setzen Sie ihre Position zurück, indem Sie Alt+G drücken. Drücken Sie dann die Schaltfläche Restore Collections, um sie bearbeitbar zu machen.

.. image:: img/DalcoRestore.gif

Wählen Sie einen der Platzhalter auf der 959 Mini aus, wählen Sie dann per Rahmenauswahl alle aus und drücken Sie im KRK-Panel im Bereich Relink auf Set.

.. image:: img/BoardPopulate.gif

Klicken Sie im Bereich Color auf Setup und drücken Sie dann im Bereich Color auf die Schaltfläche Paste. Damit werden die Farben abgerufen, die aus dem Kit gespeichert wurden.

|

Richten wir eine Szene ein.

|

Öffnen Sie in der Sammlung Scene die Sammlung Lights, deaktivieren Sie die Sichtbarkeitsoptionen für KitLightingHigh und aktivieren Sie SoftBoxStudio.
Aktivieren Sie FloorWood6 in der Sammlung Floors.

.. image:: img/LightsFloor6.jpg

|

Legen Sie in den Scene Properties die Kamera auf Camera_Board2 fest.

.. image:: img/SetCamera.jpg

|

Drehen Sie den 3D-Viewport in einen interessanten Winkel und richten Sie die aktive Kamera an der Ansicht aus, indem Sie auf View > Align View > Align Active Camera To View klicken (Ctrl+Alt+Numpad0).

.. image:: img/SetActiveCamera.gif

|

Rendern Sie nun Ihre Szene.

.. image:: img/TutBoardRender.jpg

|

Damit ist Beispiel-Workflow-Tutorial 2 abgeschlossen.

|
