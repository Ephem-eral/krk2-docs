KRK Groupe spécial
==================

.. image:: img/krkpanel204.jpg

Le panneau KRK se trouve dans la barre latérale (N) et est séparé en quatre sections: Relien, données, couleur et propriétés. Les deux dernières ne sont visibles que lorsque les propriétés pertinentes sont disponibles.

|

Relien
~~~~~~
Relink est un gestionnaire données d’objet conçu pour échanger rapidement entre profils de touches, lignes, tailles, touches et options d'hooming. Toute option qui a la case activée sera prise en compte lorsque vous appuyez sur le bouton Set.

|

Importer KLE
------------
KRK a la capacité d'importer du clavier Disposition Editor JSON files. KLE ne nomme pas ses objets de sorte que l'importateur essaie d'interpréter les clés basées sur le légende et la ligne (K1-K6) et définit un objet substituable qu'il peut. Utilisez ce KLE comme exemple ou comme base pour générer le vôtre:

`http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a <http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a>`_

|

Profil
-------

.. image:: img/KRK2ProfileSwitch.gif

Les profils disponibles et leurs préfixes sont listés dans la collection Profile dans le profileur tandis que les lignes et autres options pour lesquelles vous développerez une intuition. Tapez l'option dans le champ pertinent (sensible aux cas) avec la case à cocher activée et appuyez sur Set pour définir l'option.

|

|

Taille
------

.. image:: img/KRK2ShiftSize.gif

Vous pouvez changer la taille d'un touche en tapant la taille de l'unité de quatre caractères dans le champ. Si la géométrie de destination est disponible, elle changera à la taille désirée.

|

Clé
----

.. image:: img/Releg.jpg

Tapez le nom touche dans le champ pour changer touches vers un autre touche. Ceci est pratique pour passer à un relégendable (Releg), à un blanc touche (Blank) ou à une fenêtre ([``*_WIN``).

|

Homing
------

.. image:: img/KRK2Homing.gif

Vous pouvez modifier le type de clé d'accueil entre la barre/nub/scoop en utilisant ce menu déroulant et en cliquant sur Set.

|

Matériel de liaison
-------------------
Link Material est une option qui vous permet de transporter le matériel courant appliqué vers la destination données d’objet. Vous pouvez vouloir que cela soit activé ou désactivé en fonction du résultat souhaité. Par exemple, si vous changez vers le profil objet substituable (PLA) vous voulez que l'option Link Material soit désactivée de sorte que le Capsmat ne soit pas transféré vers les détenteurs de place.

|

Copier les paramètres
---------------------

.. image:: img/CopySettings.jpg

Sur le côté droit du bouton Set est le bouton Copy Settings qui vous aide à copier le nom données d’objet dans la liste déroulante données d’objet pour aider à la recherche d'une clé particulière.

|

   Les sections suivantes n'afficheront que les options pour l'objet actif (en surbrillance).

|

Données
~~~~~~~

Les données reflètent les données d’objet et les sections d'assignation de matériaux du panneau de propriétés pour les rendre plus faciles d'accès.

|

Recherche facile par données d’objet pour remplacer le données d’objet actif par un autre. Par exemple, duplicata ou instance touche et faire la copie en switch ou stabilisateur.

.. image:: img/ObjectDataSwitch.gif

|

Restaurer Meshes peut être utilisé lorsqu'un touche ne peut pas être reconnecté parce qu'il a été dupliqué, importé ou collé. Ce qu'il fait est de le reconnecter avec la version nommée de la même façon qui est déjà dans le fichier. Si vous souhaitez utiliser celui importé comme base, renommer son données d’objet pour ne pas avoir.001 à la fin.

.. image:: img/RestoreMesh.gif

|

Restaurer les collections n'apparaît que lorsque vous avez un actif de collection sélectionné. Cela vous permet de le restaurer dans un état modifiable.

.. image:: img/RestoreCollection.jpg

|

Le bouton Copier ici lie le matériel de l'objet actif touche à tous les autres objets sélectionnés touches tout en ignorant les objets non-touche.

.. image:: img/MatCopy.gif

|

Couleur
~~~~~~~

Color est un système de gestion de couleurs et de palettes pour vous aider à contrôler les aspects de couleurs de votre Capsmat. Il ne s'affichera que lorsqu'il y aura des propriétés de couleurs disponibles.
Si vous avez un touche sélectionné qui ne maintient pas les propriétés de couleur, le bouton Setup sera disponible pour appliquer toutes les propriétés nécessaires à l'objet touche.

.. image:: img/ColorSetup.jpg

|

Le commutateur personnalisé/palette vous permet de switch entre les flux de travail personnalisés de la couleur et de la palette. Les couleurs A-E et Palette Sliders A-E vous permettent de contrôler ces aspects du Capsmat sur une base d'objet à travers les groupes de nœuds de palette. Choisissez vos options et appuyez sur Set pour les propager à tous les objets sélectionnés touche ou appuyez sur les boutons de copie individuels pour les limiter à une seule option à la fois.

.. image:: img/ColorSetPaste.gif

|

Propriétés
~~~~~~~~~~

Les propriétés ne sont visibles que lorsque des propriétés personnalisées sont disponibles. Pour les câbles USB, il affiche les options de câble telles que la tresse/techflexe et la couleur de la bretelle pour les têtes. Si la table de bureau est sélectionnée, il affichera à la place les options de dimension et de bordure.

.. image:: img/KRK2PanelProps.gif
