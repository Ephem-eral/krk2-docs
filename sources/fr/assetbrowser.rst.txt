Assets de matériaux
~~~~~~~~~~~~~~~~~~~
Le navigateur d'assets est préchargé avec plusieurs matériaux utiles, classés par type et par fabricant. Vous pouvez les glisser-déposer sur vos objets dans la vue 3D.

.. image:: img/AssetBrowserMaterial.gif

Utilitaires de matériaux
~~~~~~~~~~~~~~~~~~~~~~~~

.. image:: img/MaterialUtilities.JPG

Les utilitaires de matériaux peuvent être glissés dans l'éditeur de shaders pour ajouter des effets lorsque vous créez vos propres matériaux.
