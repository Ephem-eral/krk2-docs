Outliner
========
L'Outliner contient tous les éléments de votre scène, organisés en collections.

.. image:: img/Outliner.jpg

Kits
~~~~

.. image:: img/KitsCollection.jpg

La collection Kits est activée par défaut

Claviers
~~~~~~~~

.. image:: img/BoardCollection.jpg

Les claviers sont organisés par taille, puis par ordre alphabétique. Utilisez le triangle pour parcourir les sous-collections, puis les options de disposition du clavier, comme la variante de touche « stepped Caps Lock » ou la rangée inférieure Tsangan.

Dispositions
~~~~~~~~~~~~

.. image:: img/DuplicateLinkedCollection.gif

Il s'agit de dispositions supplémentaires que vous pouvez utiliser pour peupler un clavier personnalisé que vous avez importé. Faites un clic droit sur la disposition et choisissez Dupliquer lié pour créer une collection liée, puis déplacez-la dans la collection de votre clavier.

Accessoires
~~~~~~~~~~~
Les accessoires disponibles sont listés ici : un modèle de tapis de bureau, une souris, des câbles USB et un repose-poignets.

Scène
~~~~~

.. image:: img/SceneCollection.jpg

C'est ici que vous accéderez aux éléments de votre scène, tels que les lumières, les caméras et les arrière-plans.

Caméras
-------
Les caméras ont été réduites dans KRK2, mais vous pouvez les dupliquer pour définir vos propres angles, etc.

Lumières
--------

.. image:: img/LightsCollection.jpg

Différents éclairages ont été créés pour vous aider à définir l'aspect général de votre scène. Ils sont basés sur des configurations HDRI de studio populaires, mais offrent plus de liberté et de réglages. N'hésitez pas à ajuster l'intensité et le positionnement de ces lumières.

Sols
----

.. image:: img/FloorsCollection.jpg

KRK est livré avec un ensemble de sols intéressants pour vous aider à démarrer. Cela inclut un sol ShadowCatcher basé sur FloorLightGrey, qui capture l'ombre pour les rendus sur fond transparent.
