FAQ
~~~

|

Comment installer Keyboard Render Kit ?
---------------------------------------

Keyboard Render Kit est entièrement contenu dans le fichier blend, auquel vous accédez en ouvrant simplement le fichier dans Blender.

|

Pourquoi Blender me demande-t-il d'exécuter un script ?
-------------------------------------------------------

KRK2 comprend un module complémentaire qui fonctionne sans installation séparée grâce à l'exécution d'un script enregistré.

|

Où sont mes touches ?
---------------------

KRK2 propose un nouveau flux de travail qui utilise des objets substituables et les remplace par le profil de touches de votre choix via le panneau KRK.

|

Mon navigateur d'assets est vide.
---------------------------------

Blender a besoin d'un fichier annexe pour spécifier quels éléments peuplent le navigateur d'assets et dans quelles catégories. Vous remarquerez qu'un fichier txt se trouve dans le fichier zip ; il doit accompagner le fichier blend dans le dossier où il se trouve.

|

Les claviers n'apparaissent pas dans le navigateur d'assets.
------------------------------------------------------------

La prise en charge des assets de collection est arrivée avec Blender 3.2 ; vous devez donc vous assurer d'utiliser Blender 3.2 ou une version plus récente.

|

Mes touches n'ont aucun matériau.
---------------------------------

Les modèles de touches de KRK2 sont fournis sans matériau par défaut. Ainsi, les touches et le capsmat peuvent être mis à jour indépendamment.

|
