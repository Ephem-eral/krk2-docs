KRK vers 3ds Max
================
L'exportation vers 3ds Max est assez simple. Cependant, quelques opérations préalables sont nécessaires. 3ds Max ne gère pas aussi bien les ngones que Blender, mais il adore les triangles et les quads. Donnons-lui donc ce qu'il attend.

.. image:: img/krk2maxstart.jpg

|

Une fois votre clavier ou kit prêt, masquez tous les autres objets qui ne doivent pas faire partie de l'exportation. Il s'agira probablement de la collection de la scène, désactivez-la donc.

.. image:: img/TurnOffSceneCollection.gif

|

Une fois que seuls les éléments de votre clavier ou de votre kit sont visibles, sélectionnez l'un de ces objets puis sélectionnez tout en appuyant sur A au clavier. Appuyez ensuite sur Tab pour passer en mode édition sur tous les objets sélectionnés.

.. image:: img/KeyboardVertices.jpg

|

Vous devez être en mode sélection de faces. Le raccourci est 3 sur la rangée de chiffres.

.. image:: img/FaceMode.jpg

|

Désélectionnez tout en appuyant deux fois de suite sur A ou sur Alt+A.

.. image:: img/KeyboardFaces.jpg

|

Allez maintenant dans Select > Select By Trait > Faces By Sides.

.. image:: img/FaceBySides.gif

|

Utilisez la fenêtre contextuelle en bas à gauche pour définir le type sur Greater Than.

.. image:: img/SelectGreaterThan.jpg

|

Tous les ngones, et uniquement les ngones, sont maintenant sélectionnés.

.. image:: img/KeyboardNgons.jpg

|

Cliquez ensuite sur Face > Triangulate Faces ou sur Ctrl+T, puis appuyez sur Tab pour quitter le mode édition.

.. image:: img/KeyboardTriangulate.gif

|

Votre clavier est maintenant prêt pour l'exportation. Cliquez sur File > Export > FBX. Donnez un nom à votre fichier, réglez Path Mode sur Copy et n'oubliez pas de vérifier que Limit to Selected Objects est bien coché.

.. image:: img/krk2maxexportsettings.png

|

Maintenant, dans Max, importez votre fbx.

.. image:: img/krk2maximported.png

|
