Profils
========
CHE
~~~~
Profil Cherry remodelé d'après Endeavour. Utilisez l'extension -2 pour les dessous. Utilisez le modèle de légende Cherry. Inclut la prise en charge de la légende frontale.

DCS
~~~~
Profil DCS remodelé d'après Fooblitzky. Utilisez l'extension -2 pour les dessous. Utilisez le modèle de légende DCS. Inclut la prise en charge de la légende frontale.

DSA
~~~~
Dérivé du modèle DSA de KRK1. Utilisez le modificateur subdivision pour lisser les côtés.

DSS
~~~~
Dérivé du modèle DSS de KRK1. Utilisez le modificateur subdivision pour lisser les côtés.

KAM
~~~~
Dérivé du modèle KAM de KRK1. Utilisez le modificateur subdivision pour lisser les côtés.

KAT
~~~~
Dérivé du modèle KAT de KRK1. Utilisez le modificateur subdivision pour lisser les côtés.

OEM
~~~~
Dérivé du modèle OEM de KRK1.

SA
~~~~
Dérivé du modèle SA de KRK1. Utilisez le modificateur subdivision pour lisser les côtés.

Profils supplémentaires
=======================

KRK
~~~~
Modèles de touches KRK1 incluant l'interface de switch. Doivent être importés.

PBS
~~~~
Profil PBS, avec tiges. Doit être importé.

PLA
~~~~
Profil substituable.

SLK
~~~~
Profil SLK, avec tiges. Doit être importé.
