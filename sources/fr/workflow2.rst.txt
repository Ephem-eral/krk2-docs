Premier rendu de clavier
=========================
Maintenant que vous connaissez les bases, effectuons le rendu d'un clavier. Nous allons approfondir ce que nous avons appris dans le premier tutoriel.

|

Dans un nouveau fichier KRK2, appuyez sur A dans la vue 3D pour tout sélectionner, puis appuyez sur le bouton Set dans la section Relink du panneau KRK pour leur attribuer le profil Cherry.
Faites glisser le Capsmat depuis le navigateur d'assets sur l'une des touches. Faites Shift+clic sur la même touche pour en faire l'objet actif et appuyez sur le bouton Copy dans la section Data du panneau KRK.

.. image:: img/SetCapsmatCopy.gif

|

Cliquez maintenant sur Copy dans la section Color du panneau KRK. Cela enregistre les informations de couleur pour les rappeler ultérieurement.

.. image:: img/CopyColors.JPG

|

.. note:: Si vous ne prévoyez pas de post-traitement sur votre image finale (non recommandé), réglez au moins le profil de gestion des couleurs sur « Standard » ou réglez le look sur « Medium High Contrast ».

|

Masquez maintenant la collection Kits à l'aide des options de visibilité dans l'Outliner.

.. image:: img/TurnOffKits.gif

|

Faites glisser le clavier Dalco 959 Mini WKL depuis le navigateur d'assets et réinitialisez sa position en appuyant sur Alt+G, puis appuyez sur le bouton Restore Collections pour le rendre modifiable.

.. image:: img/DalcoRestore.gif

Sélectionnez l'un des objets substituables sur le 959 Mini, puis effectuez une sélection par rectangle sur tous et appuyez sur Set dans la section Relink du panneau KRK.

.. image:: img/BoardPopulate.gif

Cliquez sur Setup dans la section Color, puis appuyez sur le bouton Paste dans la section Color. Cela rappelle les couleurs enregistrées depuis le kit.

|

Configurons une scène.

|

Dépliez la collection Scene jusqu'à Lights, désactivez les options de visibilité de KitLightingHigh et activez SoftBoxStudio.
Activez FloorWood6 dans la collection Floors.

.. image:: img/LightsFloor6.jpg

|

Dans les propriétés de la scène, définissez la caméra sur Camera_Board2.

.. image:: img/SetCamera.jpg

|

Faites pivoter la vue 3D vers un angle intéressant et alignez la caméra active sur la vue en cliquant sur View > Align View > Align Active Camera To View (Ctrl+Alt+Numpad0).

.. image:: img/SetActiveCamera.gif

|

Effectuez maintenant le rendu de votre scène.

.. image:: img/TutBoardRender.jpg

|
