Restore Collection Instances
======================================

.. image:: img/RCI_Banner.jpg


Restore Collection Instances est un addon simple, développé pour combler une lacune de Blender : les assets de collection ne sont pas correctement restaurés par la fonction « Make Instances Real » native de Blender. Blender ne conserve pas la hiérarchie de collection d'origine, même si la hiérarchie parentale, elle, peut être maintenue.

|

Comparez les résultats de Make Instances Real avec l'option de maintien de la hiérarchie activée, puis avec Restore Collection Instances.

.. image:: img/RCIvsMIR.jpg

Dans cet exemple, l'asset de collection d'origine contenait 176 objets, dont certains étaient masqués par les options de visibilité. La fonction Make Instances Real n'en a restauré que 161 et a perdu toutes les collections, l'organisation et les couleurs.

|

.. image:: img/KRK2Divider.jpg

|

Bien que Restore Collection Instances ait été développé à l'origine dans le cadre de Keyboard Render Kit, nous avons rapidement réalisé que cet outil serait utile de manière générale.

|

.. image:: img/KRK2Divider2.jpg

|

Pour utiliser l'outil, appuyez simplement sur ctrl+A et sélectionnez Restore Collection Instances dans le menu Apply.

.. image:: img/RestoreCollectionInstances.jpg
