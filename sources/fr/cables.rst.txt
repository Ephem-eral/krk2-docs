Câble droit
~~~~~~~~~~~~~~
Le câble simple USB est une exception en ce sens qu'il est conçu pour s'étendre infiniment en éditant l'objet courbe et en ajoutant des sommets en subdivisant les segments.

.. image:: img/CableSubdiv.gif

|

Matériau
~~~~~~~~

Comme pour le dukmat, pour modifier le matériel, vous devrez modifier les matériaux appliqués ou les remplacer via la section modificateurs des propriétés de l'objet.

.. image:: img/CableMaterial.jpg

|

.. _ExportingCables:

Exportation de câbles
~~~~~~~~~~~~~~~~~~~~~

Si vous exportez le câble vers un autre logiciel, le câble n'aura pas de UV map et devra être converti à partir d'un attribut. Sélectionnez l'objet câble (fil) et appuyez sur ctrl+A puis choisissez la géométrie visuelle en Mesh.

.. image:: img/CurveToMesh.gif

|

Une fois cela fait, il y aura un attribut dans les données de l'objet qui peut être converti en un UV map en utilisant le menu déroulant dans Attributs dans Données d’objet Propriétés. Définissez le mode en UV map et appuyez sur OK.

.. image:: img/AttrToUV.gif

|

Votre câble est maintenant prêt à être exporté.
