.. _cables:

Câbles USB
==========
Plusieurs configurations de câble USB sont disponibles.

.. image:: img/USBCables.JPG

|

Utilisez les poignées pour orienter le câble comme vous le souhaitez.

.. image:: img/CableHandle.gif

|

Les embouts USB sont interchangeables avec d'autres types via les données d'objet.

.. image:: img/CableHeads.gif

|

Les connecteurs Aviator et LEMO sont interchangeables et peuvent être débranchés.

.. image:: img/CableLEMO.gif

|

Paramètres
~~~~~~~~~~
Les paramètres sont distincts pour chaque objet et chaque segment de câble.

.. image:: img/CableProps.JPG

|

Plug
----
Ce paramètre reconnecte le connecteur LEMO ou Aviator.

.. image:: img/CablePlug.gif

|

Couleur
-------
Les couleurs 1 et 2 fournissent au matériau la couleur et la couleur d'accentuation.

.. image:: img/CableColor.gif

|

Retourner
---------
Ce paramètre retourne la spirale verticalement.

.. image:: img/CableFlip.gif

|

Miroir
------
Ce paramètre applique un miroir horizontal au câble.

.. image:: img/CableMirror.gif

Tech Flex
---------
Ce paramètre fait passer le câble d'une tresse à une gaine Tech Flex.

.. image:: img/CableTechFlex.gif

|

Câble droit
~~~~~~~~~~~
Le câble USB simple fait exception : il est conçu pour s'étendre à l'infini en modifiant l'objet courbe et en ajoutant des sommets par subdivision des segments.

.. image:: img/CableSubdiv.gif

|

Matériau
~~~~~~~~

Comme pour le tapis de bureau, pour changer le matériau, vous devez modifier les matériaux appliqués ou les remplacer via la section des modificateurs dans les propriétés de l'objet.

.. image:: img/CableMaterial.jpg

|

.. _ExportingCables:

Exportation des câbles
~~~~~~~~~~~~~~~~~~~~~~

Pour exporter le câble vers un autre logiciel, vous devez créer une UV map à partir d'un attribut. Sélectionnez d'abord l'objet câble (wire) et appuyez sur ctrl+A, puis choisissez Visual Geometry to Mesh.

.. image:: img/CurveToMesh.gif

|

Une fois cela fait, un attribut sera présent dans les données de l'objet et pourra être converti en UV map via le menu déroulant dans Attributes des propriétés des données d'objet. Réglez le mode sur UV Map et validez.

.. image:: img/AttrToUV.gif

|

Votre câble est maintenant prêt à être exporté.
