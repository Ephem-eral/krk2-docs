歡迎使用 Keyboard Render Kit！

歡迎使用 Keyboard Render Kit 2，感謝你的支援！

KRK2 延續了 KRK1 的物件資料替換工作流程，並讓它更靈活、更獨立、顆粒度更細。鍵帽高度不再依賴其他模型的幾何體，鍵盤可以自由移植，各元件都能獨立於版本單獨更新。


執行要求

Blender 3.3 或更高版本

一臺能跑 Blender Cycles 的電腦

相關連結

Gumroad | BlenderMarket | Instagram | Discord | 字根資源庫


快速上手

包裝內容

在下載頁面裡，你會拿到一個壓縮包，裡面包含一個 blend 檔案、一個 txt 檔案，以及若干與字根模板（legend template）相關的 SVG 和其他素材。請解壓縮到同一個資料夾，讓它們放在一起。這個 txt 檔案是 Blender 資產管理的配套檔案（sidecar），必須和 blend 檔案放在一起。


開始使用

KRK2 的上手流程和初代 KRK 一樣簡單。用 Blender（3.3 或更高版本）開啟 blend 檔案，你需要的東西全都打包在檔案裡了。開啟時 Blender 會詢問是允許還是忽略檔案內建的腳本——KRK2 面板依賴這個腳本執行，所以這裡選「允許」。


取得幫助

加入我們的社群： Discord

配套資料可以查 Blender 官方手冊。


介面

KRK2 的介面佈局最接近 Blender 的「著色」（Shading）工作區，區別是左欄由檔案瀏覽器和影像編輯器換成了資產瀏覽器和 UV 編輯器，側邊欄裡還多了一個 KRK 頁籤。


資產瀏覽器

資產瀏覽器收錄了大量實用材質，按類型和廠商分類。

Blender 手冊：資產瀏覽器


UV 編輯器

這個面板既能當影像檢視器，也能顯示鍵帽上字根的座標。

Blender 手冊：UV 編輯器


3D 視圖

你在這裡編輯套件、配列、燈光、機位角度等。側邊欄上掛著 KRK 面板，用來控制鍵帽。

Blender 手冊：3D 視圖


著色器編輯器

你在這裡控制材質的外觀與屬性。

Blender 手冊：著色器編輯器


大綱視圖

這裡展示 blend 檔案的層級結構。套件、鍵盤、配列、配件、攝影機、燈光、地面、鍵帽高度等都在這裡，同時也能控制它們的可見性。

Blender 手冊：大綱視圖


屬性

其餘大部分屬性分佈在各頁籤中。

Blender 手冊：屬性編輯器


KRK 面板

KRK 面板在側邊欄（按 N 呼出）裡，分為四個區域：Relink、Data、Color 和 Properties。最後兩個區域只在對應屬性可用時才出現。


Relink（重新連結）

Relink 是物件資料管理器，用來快速切換鍵帽高度、行、尺寸、按鍵類型和定位鍵（homing）。凡是勾選的選項，按 Set 時都會生效。


匯入 KLE

KRK 可以匯入 Keyboard Layout Editor 的 JSON 檔案。KLE 不給物件命名，所以匯入器會根據字根和行（K1-K6）來推斷按鍵，並在能推斷的地方放置佔位符。可以用這個 KLE 作為範例，或者以它為基礎產生你自己的配列：

http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a


Profile（高度）

可用的高度和它們的前綴在大綱視圖的 Profile 集合裡；行和其他選項用幾次就有感覺了。把選項填進對應輸入框（區分大小寫），勾選後按 Set 生效。

Size（尺寸）

在輸入框裡填入四位字根的尺寸單位（unit size）就能改變鍵帽尺寸；只要目標幾何體存在，鍵帽就會變成你要的大小。


Key（按鍵）

在輸入框裡填鍵帽名稱，就能把鍵帽換成別的鍵帽。想換成可換字鍵帽（Releg）、無刻鍵帽（Blank）或開窗鍵帽（*_WIN）時特別方便。


Homing（定位鍵）

用這個下拉選單在橫槓／凸點／凹面（bar/nub/scoop）之間切換定位鍵類型，然後點 Set。


Link Material（連結材質）

Link Material 可以把目前已應用的材質帶到目標物件資料上。要開還是要關取決於你想要的結果：比如換成佔位符高度（PLA）時，就該把它關掉，免得 Capsmat 也帶到佔位符上。


Copy Settings（複製設定）

Set 按鈕右側是 Copy Settings，它把物件資料名複製到物件資料下拉選單裡，方便查詢某個特定按鍵。


以下區域只顯示目前啟用（高亮）物件對應的選項。


Data（資料）

Data 把屬性面板裡的物件資料和材質指派搬了過來，存取更方便。


在這裡可以快速搜尋物件資料，把目前的換成另一個。例如複製或實例化一個鍵帽，再把副本變成軸體或衛星軸。


鍵帽因為複製、匯入或貼上而無法重新連結時，用 Restore Meshes 就能把它和檔案裡同名的版本重新接上。如果你想以匯入進來的那個為基準，就把它的物件資料重新命名，去掉結尾的 .001。


Restore Collections 只在選取集合資產時出現，用來把它還原成可編輯狀態。


這裡的 Copy 會把目前啟用鍵帽上的材質連結到其他所有選取的鍵帽，同時忽略非鍵帽物件。


Color（顏色）

Color 是一套顏色與色板管理系統，幫你控制 Capsmat 裡和顏色相關的屬性，只在顏色屬性可用時顯示。 如果選取的鍵帽沒有顏色屬性，會出現 Setup 按鈕，用來給這個鍵帽補上所需的全部屬性。


Custom/Palette 開關讓你在自訂顏色和色板兩套工作流程之間切換。顏色 A-E 和色板滑桿 A-E 透過色板節點組，讓你逐個物件地控制 Capsmat 的這些部分。選好後按 Set 會應用到所有選取的鍵帽；也可以按各自的複製按鈕，一次只複製一項。底部的 Copy 和 Paste 用來為所有選取物件建立並叫回一套選項記錄。


Properties（屬性）

Properties 同樣只在自訂屬性可用時顯示：選取 USB 線材顯示線材選項，比如編織／TechFlex 和接頭熱縮管的顏色；選取桌墊則顯示尺寸和包邊選項。


資產瀏覽器

配件資產

配件在 Accessory（配件）分類下。

鍵盤資產

鍵盤模型在 Boards（鍵盤）分類下。

材質資產

資產瀏覽器預置了許多實用材質，並按類型和廠商分類，可以直接拖到 3D 視圖裡的物件上。


材質工具

自己動手做材質時，可以把這些工具拖進材質編輯器來新增效果。


UV 編輯器

UV 編輯器既是影像檢視器，也是 UV 座標編輯器：你可以直觀地看到一張 2D 影像作為字根貼到 3D 空間後會是什麼效果。


想深入瞭解 Blender 的 UV 座標，看 Blender 手冊：UV 說明。


著色器編輯器

選取物件後，它身上應用的材質就能在材質編輯器裡編輯，而且只針對目前啟用（高亮）的這一個物件。


用下拉選單可以給物件換一個材質。


如果想讓某個材質獨立出來、改它時不影響其他物件，可以點選名稱旁邊的數字（表示有多少個物件在用這個材質），點一下就會複製出一份新材質。點「新增材質」按鈕也是一樣的效果。


影像紋理節點需要座標，才能確定如何把 2D 影像貼到 3D 物件上。如果向量（Vector）輸入沒有接入任何座標，就會使用目前啟用的 UV。

有些材質含有被靜音的節點（顯示為灰色），渲染時不參與計算。要啟用，左鍵點選該節點，按 M 取消靜音即可。


世界材質也能在材質編輯器裡編輯：點左上角顯示為 Object 的下拉選單，改成 World。


大綱視圖

大綱視圖收納場景中的所有項目，並把它們組織成集合。

套件

Kits（套件）集合預設開啟。

鍵盤

鍵盤先按尺寸分組，同尺寸內按字母順序排列。點選三角箭頭可以逐層展開子集合，再往下就是鍵盤的配列選項，例如階梯 CapsLock 或 Tsangan 底排。

配列

這些是備用配列，可用來填充自己匯入的鍵盤。右鍵點選配列並選擇「關聯複製」，產生一個關聯集合，再把它移到你的鍵盤所屬的集合裡。

配件

這裡列出可用的配件，包括桌墊模型、滑鼠、USB 線和手托。

場景

在這裡可以檢視場景元素，比如燈光、攝影機和背景。

攝影機

KRK2 對攝影機做了精簡，不過你可以複製它們，自行設定機位和角度。

燈光

我們準備了多套燈光方案，幫你確定場景的整體觀感。它們參考了流行的影棚燈光 HDRI 方案，可調性更高，強度和位置都能隨意調整。

地面

KRK 自帶一組挺有意思的地面，方便你快速上手。其中包括陰影捕捉（ShadowCatcher）地面，它以 FloorLightGrey 為基礎，專門捕捉陰影，用於渲染透明背景。

結構

鍵帽高度

所有鍵帽高度都在這裡。

UV 設定

這個集合包含為鍵帽做 UV 投影所需的全部內容。

零件

這裡收錄了一些額外零件，可以透過物件資料替換加到自己的鍵盤上。

屬性編輯器

Blender 的屬性面板內容極多，這裡只挑幾個最相關的部分講。


渲染屬性

渲染裝置

你可以用 GPU（顯示卡）加速渲染。注意：還得在偏好設定裡配好運算裝置才會生效。

取樣

視埠預設取樣 32，最終渲染 256。如果要渲染聚碳酸酯（PC）材質，我強烈建議至少開到 512。

降噪

降噪在這裡設定。我通常把視埠降噪開啟並設為自動，起始取樣設為 2 或更高，讓視埠保持流暢。最終渲染的降噪也可以在合成器裡做。

膠片透明

要渲染透明背景的影像，需要開啟 Film（膠片）> Transparent（透明）。

色彩管理

這一節很重要。Blender 色彩管理預設是 Filmic，我這裡也保持預設、不套用 look。有些使用者更喜歡設為 Standard，因為感覺更容易對齊顏色。我個人更偏好 Filmic：高光過渡更柔和，再配合 Medium High Contrast，觀感非常接近 Standard，但明暗層次更好。如果打算匯出 EXR，這裡的選項無所謂——EXR 匯出的就是完整緩衝區資料。


輸出屬性

解析度

這裡設定輸出影像的解析度。在做 UV 投影這類操作時，解析度同樣會影響結果。


提示：目前是 2K 而你想設成 4K，可以直接在輸入框裡填 200%，而不是 100%。


場景屬性

作用中攝影機

這裡設定按渲染時 Blender 使用哪臺攝影機。


物件資料屬性

物件資料

別跳過 Object Data（物件資料）下拉選單：選一項，就能把任意物件換成另一種物件。

UV 貼圖

需要存取某個物件的 UV 貼圖時，就在這裡找。


材質屬性

材質索引

一個物件可以掛多個材質。比如開窗鍵帽和可換字鍵帽就有兩個材質槽：一個鍵帽材質，一個聚碳酸酯（PC）。

材質連結

你可以逐個物件地告訴 Blender：用物件資料上的材質，還是物件本身的材質。


色彩管理

Blender 的色彩管理基於線性色彩空間，視圖變換（View Transform）預設是 AGX（4.0 之前為 Filmic）。這些視圖變換能容納很寬的動態範圍，但不做後期處理時，你選好的顏色會顯得偏灰、對比度偏低。


這套工作流程的前提是你打算做後期處理，把顏色調得更接近真實效果。願意這麼做的人並不多（尤其是新使用者），所以從 KRK 211 起，KRK 預設採用 Filmic + Medium High Contrast，再在後期（合成器）裡把 Filmic 轉成 sRGB，得到更符合預期的結果。


視埠已經設定好，你看到的內容都會經過合成器處理。如果新增 3D 視埠，記得把合成（compositing）設為 Always，顏色才會被正確還原。


記住，最終以你的眼睛為準：永遠拿實物參考做對比。

Capsmat（鍵帽材質）

設定項

Cap（鍵帽底色）

鍵帽的底色。可以直接用顏色欄位調，也可以接入色板（palette）來控制。

Legend（字根）

字根的顏色。可以選一個顏色、接色板來控制，也可以把影像接入插槽，做出全彩字根。

Legend Mask（字根遮罩）

接入一張黑底白字的影像，用來在鍵帽底色和字根顏色之間做混合。

Sharpen Legend（字根銳化）

用來銳化字根邊緣，做出二色成型（doubleshot）字根的效果。預設拉滿，可以滑到 0，模擬更接近熱昇華（dye sublimation）的觀感。

Legend Weight（字根粗細）

因為字根銳化的原理所限，你還可以用它來加粗字根：數值越小，字根越粗。

Sub（副字根）

這是副字根的顏色。

SubMask（副字根遮罩）

用來接入副字根檔案的插槽。

Sharpen Sub（副字根銳化）

和字根銳化一樣，只是作用於副字根。

Sub Weight（副字根粗細）

和字根粗細一樣，只是作用於副字根。

Front（側刻）

這是側刻的顏色。

Front Mask（側刻遮罩）

這是側刻遮罩的插槽。

Shapen Front（側刻銳化）

和字根銳化一樣，只是作用於側刻。

Front Weight（側刻粗細）

和字根粗細一樣，只是作用於側刻。

Roughness（粗糙度）

鍵帽材質整體的粗糙度（也就是光澤感）。具體數值取決於你想要哪種塑膠或表面處理，比如 PBT 通常比 ABS 更粗糙。

Bump Scale（凹凸比例）

凹凸雜訊的縮放比例（也就是顆粒大小）。可以理解成砂紙的目數：數值越大，顆粒越密。

Top Bump（頂部凹凸）

這是鍵帽頂部凹凸的強度。

Side Bump（側面凹凸）

鍵帽後側、前側和左右兩側凹凸的強度。

Legend Seam（字根接縫）

有些二色成型製程會在字根和鍵帽之間留下更明顯的接縫。


遮罩

遮罩是一張黑底白字的影像，用來定義兩個顏色或兩個元素如何混合。可以這樣理解：白色是「開」，黑色是「關」。


在 capsmat 裡，遮罩用來把鍵帽底色與字根、副字根、側刻分別混合。任何一項缺失，該部分就按黑色（關閉）處理。


KRK 自帶模板，做這些遮罩會簡單很多。

KLE 到 KRK

Keyboard Layout Editor 不給物件命名，但命名是 Blender 和 Keyboard Render Kit 正常工作的必要條件。Blender 會分別給物件和物件資料命名。Keyboard Render Kit 基本上不看物件名，卻非常依賴物件資料名來運作。明白這一點，從 KLE 到 KRK 的轉換就相當可靠了。


哪些東西能轉換進 KRK？轉換器會處理尺寸、字根、行（row）、顏色（鍵帽色和字根色）、位置和旋轉。後三項你可以隨便改；但改了前三項、又沒有對應的目標物件資料，鍵帽就可能匯入不了。


Keyboard Layout Editor 範例


這個配列是 KLE 到 KRK 轉換的測試基準，能順利載入 KRK，是很好的參考範本。如果你還沒開始做自己的配列，從這裡起步很合適。它看起來可能有點眼熟——KRK 裡鍵帽的 UV 和貼圖用的就是這個配列。



留意字根和行的命名，因為它們才是轉換時真正起作用的東西；改了它們可能就完全轉換不過去。記住，字根本身不會被轉換，它只充當鍵帽的名字——進入 Blender 之後，透過字根遮罩，鍵帽可以顯示任意字根。

最佳化你的渲染

除了場景複雜度，還有幾個主要因素會影響渲染時間和畫質。


解析度

解析度對渲染耗時影響很大。太低會讓畫面出現畫素塊，斜線發鋸齒，細節也缺少應有的銳利度。

舉例：把百分比滑桿設為 200%，解析度從 2K 翻倍到 4K，畫質確實更精細，但電腦要處理的畫素量變成四倍。換來的影像更清晰，代價是渲染時間大幅增加。


渲染取樣

取樣數也是最佳化渲染的關鍵。取樣太少，畫面會出現雜訊；和解析度一樣，提高取樣能改善畫質，但渲染時間呈指數增長。


降噪

從有數字影像那天起，就有了降噪需求。不管素材是數字照片、掃描件，還是完全由電腦產生，處理方法都通用。近年來，路徑追蹤渲染推動了新演算法的發展，甚至開始用機器學習來解決。 Blender 提供了幾種降噪演算法，我們重點看下面兩種。

Optix

這是 Nvidia 的機器學習降噪演算法，可在 RTX 20 系及之後的 Nvidia 顯示卡上執行。因為它用了專用張量核心，速度非常快，代價是僅限 Nvidia 使用者。更多資訊見 NVIDIA 官方頁面。

Open Image Denoise

這是另一套機器學習降噪演算法，來自 Intel。顧名思義，它開源，能在多種 CPU 型號和架構上執行。速度不如 Optix，但效果非常出色，在帶透明度的場景裡更有優勢，比如渲染聚碳酸酯（PC）鍵盤。關於 Open Image Denoise 的更多資訊見 官網。

實際應用

兩種演算法都能在選項裡啟用，用於視埠和最終渲染；不過在合成器裡使用時，Open Image Denoise 更快。KRK 已經把合成器節點搭好了，你只要用合成器面板左上角的核取方塊啟用即可。


想深入瞭解降噪，看 Blender 手冊：減少雜訊。


Poly Haven 素材

鍵盤準備好了，鍵帽高度和配色也定了，攝影機取景也不錯，但燈光和地面就是達不到想要的效果。


KRK 預置了多種地面和燈光方案供你起步，不過你可能想換別的地面和燈光，讓畫面更豐富。Poly Haven 是個很好的資源站，既有用來承載鍵盤的表面，也有用來照亮場景的 HDRI（高動態範圍影像）。下面走一遍匯入流程。


如果你已經裝了 Poly Haven 外掛，這套流程大部分都能跳過；如果你經常這麼做，我強烈推薦裝一個。


地面

先存取 Poly Haven 網站（polyhaven.com），點選頂部欄的 Assets > Textures。


裡面有多個分類，這裡點 Floor > Indoor > Man-Made，然後選 Slab Tiles。


點下載按鈕，等 zip 下完，把它解壓縮到對應資料夾。你會看到資料夾裡有一個 blend 檔案，說明裡面已經有一個配置好、可以直接用的物件。


要匯入 blend 檔案的內容，得用 Append 或 Link。這裡選擇 append 地面，並且不與原檔案保持連結。在 Blender 裡點選 File > Append，開始匯入 Poly Haven 地面，接著選擇 Object 子分類，找到地面物件，它很可能叫 「Plane」。


它會被追加到大綱視圖裡目前啟用的集合中。地面進場景之後，就可以動手調整了。


預設的幾何體太少，置換（displacement）推不出細節，而且貼圖比例在這個場景裡偏大。接一個 Value 節點到比例（scale）上設為 2，把比例放大一倍。按我的機位角度，我還用對映節點把貼圖移了 80mm。再到修改器頁籤裡把細分修改器級別改成 10，讓幾何體足夠密，撐得起置換影像的細節。


既然用了置換，把地面往下移一點也很有必要：這一個往下移了 7mm。地面現在可以用於渲染了。


環境

記住：HDRI 能提升真實感，但也會影響顏色。拍鍵盤和場景沒問題，但對顏色準確性要求很高的套件渲染就不合適了。要加 HDRI，到 Poly Haven 點 Assets > HDRIs，挑一個下載。這裡用 Leadenhall Market，下載下來是 EXR 影像檔案。


在大綱視圖裡停用 Lights 集合。


然後在材質編輯器裡點左上角的下拉選單，從 Object 切到 World。世界材質已經搭好了：選取影像節點按 M 取消靜音，再點 Open 載入 Leadenhall Market 影像。


想調整這張圖，可以新增 Mapping 節點和 Texture Coordinate 節點，按圖裡那樣連線。這裡我把影像轉了 52 度，讓鍵盤右側邊緣出現一道好看的高光，同時把 HDRI 強度提高一倍。

KRK 到 3ds Max

匯出到 3D Studio Max 相當簡單，不過有幾件事要先做：3ds Max 處理多邊形（N 邊形）不如 Blender，但它很喜歡三角形和四邊形，所以我們就給它想要的。


鍵盤或套件準備好後，把不參與匯出的其他物件都隱藏起來——通常包括場景集合，把它關掉。


只剩它可見時，選取其中一個物件，按 A 全選，再按 Tab 讓所有選取的物件一起進入編輯模式。


需要處在面選擇模式，快速鍵是數字行的 3。


連按兩次 A（或按 Alt+A）取消所有選擇。


接著點 Select > Select By Trait > Faces By Sides。


用左下角的彈出面板把類型設為 Greater Than（大於）。


現在所有 N 邊形（而且只有 N 邊形）都被選取了。


然後點 Face > Triangulate Faces，或按 Ctrl+T 三角化，再按 Tab 退出編輯模式。


鍵盤現在可以匯出了：點 File > Export > FBX，起個檔名，把 Path Mode 設為 Copy，記得勾選 Limit to Selected Objects（僅限選取物件）。


接著在 Max 裡匯入這個 FBX。


KRK 到 Cinema 4D

匯出到 Cinema 4D 很簡單。

鍵盤或套件準備好後，把不想匯出的其他物件隱藏或關閉顯示。


按鍵盤上的 A 鍵全選。


點 File > Export > FBX，起個檔名，別忘了勾選 Limit to Selected Objects（僅限選取物件）。


接著在 Cinema 4D 裡匯入 FBX，然後點 Tools > Axis > Reset Scale，以及旁邊的齒輪圖示來應用縮放。


在選項裡把兩個核取方塊都勾選。


常見問題（FAQ）


如何安裝 Keyboard Render Kit？

Keyboard Render Kit 全部打包在 blend 檔案裡，用 Blender 開啟就能用。


為什麼 Blender 提示我要執行腳本？

KRK2 有一部分外掛功能，它透過執行一個已註冊的腳本實現免安裝。


我的鍵帽去哪兒了？

KRK2 換了新的工作流程：場景裡先放佔位符，再用 KRK 面板把它們換成你選的鍵帽高度。


我的資產瀏覽器是空的。

Blender 需要一個配套（sidecar）檔案，來指定資產瀏覽器裡顯示哪些項目、歸入什麼分類。壓縮包裡那個 txt 檔案就是它，必須和 blend 檔案放在同一個資料夾裡。


鍵盤沒有出現在資產瀏覽器裡。

Blender 從 3.2 起才支援集合資產（collection asset），所以請確認版本不低於 Blender 3.2。


我的鍵帽上沒有材質。

KRK2 的鍵帽模型預設不帶材質，這樣鍵帽和 capsmat 才能各自獨立更新。

還原集合實例

Restore Collection Instances（還原集合實例）是一個小外掛，用來補上 Blender 的一個功能缺口：集合資產（collection asset）用 Blender 自帶的 「Make Instances Real」 無法正確還原——它能保留父子層級，卻保不住原始的集合層級。


下面是開啟「保持層級」選項時的 Make Instances Real 與 Restore Collection Instances 的結果對比。

這個例子裡，原始集合資產有 176 個物件，其中一部分關閉了可見性。Make Instances Real 只還原了 161 個，而且丟掉了所有集合結構、組織方式和顏色。



Restore Collection Instances 最初只是 Keyboard Render Kit 的一部分，但我們很快發現它可以當通用工具用。



用法很簡單：按 Ctrl+A，在 apply（應用）選單裡就能找到它。
