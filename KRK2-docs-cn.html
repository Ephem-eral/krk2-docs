欢迎使用 Keyboard Render Kit！

欢迎使用 Keyboard Render Kit 2，感谢你的支持！

KRK2 延续了 KRK1 的物体数据替换工作流，并让它更灵活、更独立、颗粒度更细。键帽高度不再依赖其他模型的几何体，键盘可以自由移植，各组件都能独立于版本单独更新。


运行要求

Blender 3.3 或更高版本

一台能跑 Blender Cycles 的电脑

相关链接

Gumroad | BlenderMarket | Instagram | Discord | 字符资源库


快速上手

包装内容

在下载页面里，你会拿到一个压缩包，里面包含一个 blend 文件、一个 txt 文件，以及若干与字符模板（legend template）相关的 SVG 和其他素材。请解压到同一个文件夹，让它们放在一起。这个 txt 文件是 Blender 资产管理的配套文件（sidecar），必须和 blend 文件放在一起。


开始使用

KRK2 的上手流程和初代 KRK 一样简单。用 Blender（3.3 或更高版本）打开 blend 文件，你需要的东西全都打包在文件里了。打开时 Blender 会询问是允许还是忽略文件内置的脚本——KRK2 面板依赖这个脚本运行，所以这里选「允许」。


获取帮助

加入我们的社区： Discord

配套资料可以查 Blender 官方手册。


界面

KRK2 的界面布局最接近 Blender 的「着色」（Shading）工作区，区别是左栏由文件浏览器和图像编辑器换成了资产浏览器和 UV 编辑器，侧边栏里还多了一个 KRK 标签页。


资产浏览器

资产浏览器收录了大量实用材质，按类型和厂商分类。

Blender 手册：资产浏览器


UV 编辑器

这个面板既能当图像查看器，也能显示键帽上字符的坐标。

Blender 手册：UV 编辑器


3D 视图

你在这里编辑套件、配列、灯光、机位角度等。侧边栏上挂着 KRK 面板，用来控制键帽。

Blender 手册：3D 视图


着色器编辑器

你在这里控制材质的外观与属性。

Blender 手册：着色器编辑器


大纲视图

这里展示 blend 文件的层级结构。套件、键盘、配列、配件、摄像机、灯光、地面、键帽高度等都在这里，同时也能控制它们的可见性。

Blender 手册：大纲视图


属性

其余大部分属性分布在各标签页中。

Blender 手册：属性编辑器


KRK 面板

KRK 面板在侧边栏（按 N 呼出）里，分为四个区域：Relink、Data、Color 和 Properties。最后两个区域只在对应属性可用时才出现。


Relink（重新链接）

Relink 是物体数据管理器，用来快速切换键帽高度、行、尺寸、按键类型和定位键（homing）。凡是勾上复选框的选项，按 Set 时都会生效。


导入 KLE

KRK 可以导入 Keyboard Layout Editor 的 JSON 文件。KLE 不给物体命名，所以导入器会根据字符和行（K1-K6）来推断按键，并在能推断的地方放置占位符。可以用这个 KLE 作为示例，或者以它为基础生成你自己的配列：

http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a


Profile（高度）

可用的高度和它们的前缀在大纲视图的 Profile 集合里；行和其他选项用几次就有感觉了。把选项填进对应输入框（区分大小写），勾上复选框，按 Set 生效。


Row（行）

由于不同厂商、不同键帽高度使用的行编号体系各不相同，KRK 又引入了一套自己的编号，以键盘上的实际位置为准，从最后排开始数。

Size（尺寸）

在输入框里填入四位字符的尺寸单位（unit size）就能改变键帽尺寸；只要目标几何体存在，键帽就会变成你要的大小。


Key（按键）

在输入框里填键帽名称，就能把键帽换成别的键帽。想换成可换字键帽（Releg）、无刻键帽（Blank）或开窗键帽（*_WIN）时特别方便。


Homing（定位键）

用这个下拉菜单在横杠／凸点／凹面（bar/nub/scoop）之间切换定位键类型，然后点 Set。


Link Material（链接材质）

Link Material 可以把当前已应用的材质带到目标物体数据上。要开还是要关取决于你想要的结果：比如换成占位符高度（PLA）时，就该把它关掉，免得 Capsmat 也带到占位符上。


Copy Settings（复制设置）

Set 按钮右侧是 Copy Settings，它把物体数据名复制到物体数据下拉菜单里，方便查找某个特定按键。


以下区域只显示当前激活（高亮）物体对应的选项。


Data（数据）

Data 把属性面板里的物体数据和材质指派搬了过来，访问更方便。


在这里可以快速搜索物体数据，把当前的换成另一个。例如复制或实例化一个键帽，再把副本变成轴体或卫星轴。


键帽因为复制、导入或粘贴而无法重新链接时，用 Restore Meshes 就能把它和文件里同名的版本重新接上。如果你想以导入进来的那个为基准，就把它的物体数据重命名，去掉结尾的 .001。


Restore Collections 只在选中集合资产时出现，用来把它恢复成可编辑状态。


这里的 Copy 会把当前激活键帽上的材质链接到其他所有选中的键帽，同时忽略非键帽物体。


Color（颜色）

Color 是一套颜色与色板管理系统，帮你控制 Capsmat 里和颜色相关的属性，只在颜色属性可用时显示。 如果选中的键帽没有颜色属性，会出现 Setup 按钮，用来给这个键帽补上所需的全部属性。


Custom/Palette 开关让你在自定义颜色和色板两套工作流之间切换。颜色 A-E 和色板滑块 A-E 通过色板节点组，让你逐个物体地控制 Capsmat 的这些部分。选好后按 Set 会应用到所有选中的键帽；也可以按各自的复制按钮，一次只复制一项。底部的 Copy 和 Paste 用来为所有选中物体建立并调用一套选项记录。


Properties（属性）

Properties 同样只在自定义属性可用时显示：选中 USB 线材显示线材选项，比如编织／TechFlex 和接头热缩管的颜色；选中桌垫则显示尺寸和包边选项。


资产浏览器

配件资产

配件在 Accessory（配件）分类下。

键盘资产

键盘模型在 Boards（键盘）分类下。

材质资产

资产浏览器预置了许多实用材质，并按类型和厂商分类，可以直接拖到 3D 视图里的物体上。


材质工具

自己动手做材质时，可以把这些工具拖进材质编辑器来添加效果。


UV 编辑器

UV 编辑器既是图像查看器，也是 UV 坐标编辑器：你可以直观地看到一张 2D 图像作为字符贴到 3D 空间后会是什么效果。


想深入了解 Blender 的 UV 坐标，看 Blender 手册：UV 说明。


着色器编辑器

选中物体后，它身上应用的材质就能在材质编辑器里编辑，而且只针对当前激活（高亮）的这一个物体。


用下拉菜单可以给物体换一个材质。


如果想让某个材质独立出来、改它时不影响其他物体，可以点击名称旁边的数字（表示有多少个物体在用这个材质），点一下就会复制出一份新材质。点「新建材质」按钮也是一样的效果。


图像纹理节点需要坐标，才能确定如何把 2D 图像贴到 3D 物体上。如果向量（Vector）输入没有接入任何坐标，就会使用当前激活的 UV。

有些材质含有被静音的节点（显示为灰色），渲染时不参与计算。要启用，左键点选该节点，按 M 取消静音即可。


世界材质也能在材质编辑器里编辑：点左上角显示为 Object 的下拉菜单，改成 World。


大纲视图

大纲视图收纳场景中的所有项目，并把它们组织成集合。

套件

Kits（套件）集合默认开启。

键盘

键盘先按尺寸分组，同尺寸内按字母顺序排列。点击三角箭头可以逐层展开子集合，再往下就是键盘的配列选项，例如阶梯 CapsLock 或 Tsangan 底排。

配列

这些是备用配列，可用来填充自己导入的键盘。右键点击配列并选择「关联复制」，生成一个关联集合，再把它移到你的键盘所属的集合里。

配件

这里列出可用的配件，包括桌垫模型、鼠标、USB 线和手托。

场景

在这里可以访问场景元素，比如灯光、摄像机和背景。

摄像机

KRK2 对摄像机做了精简，不过你可以复制它们，自行设置机位和角度。

灯光

我们准备了多套灯光方案，帮你确定场景的整体观感。它们参考了流行的影棚灯光 HDRI 方案，可调性更高，强度和位置都能随意调整。

地面

KRK 自带一组挺有意思的地面，方便你快速上手。其中包括阴影捕捉（ShadowCatcher）地面，它以 FloorLightGrey 为基础，专门捕捉阴影，用于渲染透明背景。

结构

键帽高度

所有键帽高度都在这里。

UV 设置

这个集合包含为键帽做 UV 投影所需的全部内容。

零件

这里收录了一些额外零件，可以通过物体数据替换加到自己的键盘上。

属性编辑器

Blender 的属性面板内容极多，这里只挑几个最相关的部分讲。


渲染属性

渲染设备

你可以用 GPU（显卡）加速渲染。注意：还得在偏好设置里配好计算设备才会生效。

采样

视口默认采样 32，最终渲染 256。如果要渲染聚碳酸酯（PC）材质，我强烈建议至少开到 512。

降噪

降噪在这里设置。我通常把视口降噪打开并设为自动，起始采样设为 2 或更高，让视口保持流畅。最终渲染的降噪也可以在合成器里做。

胶片透明

要渲染透明背景的图像，需要打开 Film（胶片）> Transparent（透明）。

色彩管理

这一节很重要。Blender 色彩管理默认是 Filmic，我这里也保持默认、不套用 look。有些用户更喜欢设为 Standard，因为感觉更容易对齐颜色。我个人更偏好 Filmic：高光过渡更柔和，再配合 Medium High Contrast，观感非常接近 Standard，但明暗层次更好。如果打算导出 EXR，这里的选项无所谓——EXR 导出的就是完整缓冲区数据。


输出属性

分辨率

这里设置输出图像的分辨率。在做 UV 投影这类操作时，分辨率同样会影响结果。


提示：当前是 2K 而你想设成 4K，可以直接在输入框里填 200%，而不是 100%。


场景属性

活动摄像机

这里设置按渲染时 Blender 使用哪台摄像机。


物体数据属性

物体数据

别跳过 Object Data（物体数据）下拉菜单：选一项，就能把任意物体换成另一种物体。

UV 贴图

需要访问某个物体的 UV 贴图时，就在这里找。


材质属性

材质索引

一个物体可以挂多个材质。比如开窗键帽和可换字键帽就有两个材质槽：一个键帽材质，一个聚碳酸酯（PC）。

材质链接

你可以逐个物体地告诉 Blender：用物体数据上的材质，还是物体本身的材质。


色彩管理

Blender 的色彩管理基于线性色彩空间，视图变换（View Transform）默认是 AGX（4.0 之前为 Filmic）。这些视图变换能容纳很宽的动态范围，但不做后期处理时，你选好的颜色会显得发灰、对比度偏低。


这套工作流的前提是你打算做后期处理，把颜色调得更接近真实效果。愿意这么做的人并不多（尤其是新用户），所以从 KRK 211 起，KRK 默认采用 Filmic + Medium High Contrast，再在后期（合成器）里把 Filmic 转成 sRGB，得到更符合预期的结果。


视口已经设置好，你看到的内容都会经过合成器处理。如果新建 3D 视口，记得把合成（compositing）设为 Always，颜色才会被正确还原。


记住，最终以你的眼睛为准：永远拿实物参考做对比。

Capsmat（键帽材质）

设置项

Cap（键帽底色）

键帽的底色。可以直接用颜色字段调，也可以接入色板（palette）来控制。

Legend（字符）

字符的颜色。可以选一个颜色、接色板来控制，也可以把图像接入插槽，做出全彩字符。

Legend Mask（字符遮罩）

接入一张黑底白字的图像，用来在键帽底色和字符颜色之间做混合。

Sharpen Legend（字符锐化）

用来锐化字符边缘，做出二色成型（doubleshot）字符的效果。默认拉满，可以滑到 0，模拟更接近热升华（dye sublimation）的观感。

Legend Weight（字符粗细）

因为字符锐化的原理所限，你还可以用它来加粗字符：数值越小，字符越粗。

Sub（副字符）

这是副字符的颜色。

SubMask（副字符遮罩）

用来接入副字符文件的插槽。

Sharpen Sub（副字符锐化）

和字符锐化一样，只是作用于副字符。

Sub Weight（副字符粗细）

和字符粗细一样，只是作用于副字符。

Front（侧刻）

这是侧刻的颜色。

Front Mask（侧刻遮罩）

这是侧刻遮罩的插槽。

Shapen Front（侧刻锐化）

和字符锐化一样，只是作用于侧刻。

Front Weight（侧刻粗细）

和字符粗细一样，只是作用于侧刻。

Roughness（粗糙度）

键帽材质整体的粗糙度（也就是光泽感）。具体数值取决于你想要哪种塑料或表面处理，比如 PBT 通常比 ABS 更粗糙。

Bump Scale（凹凸比例）

凹凸噪波的缩放比例（也就是颗粒大小）。可以理解成砂纸的目数：数值越大，颗粒越密。

Top Bump（顶部凹凸）

这是键帽顶部凹凸的强度。

Side Bump（侧面凹凸）

键帽后侧、前侧和左右两侧凹凸的强度。

Legend Seam（字符接缝）

有些二色成型工艺会在字符和键帽之间留下更明显的接缝。


遮罩

遮罩是一张黑底白字的图像，用来定义两个颜色或两个元素如何混合。可以这样理解：白色是「开」，黑色是「关」。


在 capsmat 里，遮罩用来把键帽底色与字符、副字符、侧刻分别混合。任何一项缺失，该部分就按黑色（关闭）处理。


KRK 自带模板，做这些遮罩会简单很多。

KRK2 引入了新的工作流，帮你探索配色、做设计。前面你已经看到，KRK 面板能逐个控制键帽的颜色：可以先给每个键帽单独配色，再把这些颜色拖进色板，定义自己的配色方案。 色板节点组是这套工作流的另一部分。

KLE 到 KRK

Keyboard Layout Editor 不给物体命名，但命名是 Blender 和 Keyboard Render Kit 正常工作的必要条件。Blender 会分别给物体和物体数据命名。Keyboard Render Kit 基本上不看物体名，却非常依赖物体数据名来运作。明白这一点，从 KLE 到 KRK 的转换就相当可靠了。


哪些东西能转换进 KRK？转换器会处理尺寸、字符、行（row）、颜色（键帽色和字符色）、位置和旋转。后三项你可以随便改；但改了前三项、又没有对应的目标物体数据，键帽就可能导入不了。


Keyboard Layout Editor 示例


这个配列是 KLE 到 KRK 转换的测试基准，能顺利载入 KRK，是很好的参考样板。如果你还没开始做自己的配列，从这里起步很合适。它看起来可能有点眼熟——KRK 里键帽的 UV 和贴图用的就是这个配列。



留意字符和行的命名，因为它们才是转换时真正起作用的东西；改了它们可能就完全转换不过去。记住，字符本身不会被转换，它只充当键帽的名字——进入 Blender 之后，通过字符遮罩，键帽可以显示任意字符。

优化你的渲染

除了场景复杂度，还有几个主要因素会影响渲染时间和画质。


分辨率

分辨率对渲染耗时影响很大。太低会让画面出现像素块，斜线发锯齿，细节也缺少应有的锐度。

举例：把百分比滑块设为 200%，分辨率从 2K 翻倍到 4K，画质确实更精细，但电脑要处理的像素量变成四倍。换来的图像更清晰，代价是渲染时间大幅增加。


渲染采样

采样数也是优化渲染的关键。采样太少，画面会出现噪点；和分辨率一样，提高采样能改善画质，但渲染时间呈指数增长。


降噪

从有数字图像那天起，就有了降噪需求。不管素材是数字照片、扫描件，还是完全由计算机生成，处理方法都通用。近年来，路径追踪渲染推动了新算法的发展，甚至开始用机器学习来解决。 Blender 提供了几种降噪算法，我们重点看下面两种。

Optix

这是 Nvidia 的机器学习降噪算法，可在 RTX 20 系及之后的 Nvidia 显卡上运行。因为它用了专用张量核心，速度非常快，代价是仅限 Nvidia 用户。更多信息见 NVIDIA 官方页面。

Open Image Denoise

这是另一套机器学习降噪算法，来自 Intel。顾名思义，它开源，能在多种 CPU 型号和架构上运行。速度不如 Optix，但效果非常出色，在带透明度的场景里更有优势，比如渲染聚碳酸酯（PC）键盘。关于 Open Image Denoise 的更多信息见 官网。

实际应用

两种算法都能在选项里启用，用于视口和最终渲染；不过在合成器里使用时，Open Image Denoise 更快。KRK 已经把合成器节点搭好了，你只要用合成器面板左上角的复选框启用即可。


想深入了解降噪，看 Blender 手册：减少噪点。

如果你已经装了 Poly Haven 插件，这套流程大部分都能跳过；如果你经常这么干，我强烈推荐装一个。


地面

先访问 Poly Haven 网站（polyhaven.com），点击顶部栏的 Assets > Textures。


里面有多个分类，这里点 Floor > Indoor > Man-Made，然后选 Slab Tiles。


点下载按钮，等 zip 下完，把它解压到对应文件夹。你会看到文件夹里有一个 blend 文件，说明里面已经有一个配置好、可以直接用的物体。


要导入 blend 文件的内容，得用 Append 或 Link。这里选择 append 地面，并且不与原文件保持链接。在 Blender 里点击 File > Append，开始导入 Poly Haven 地面，接着选择 Object 子分类，找到地面物体，它很可能叫 “Plane”。


它会被追加到大纲视图里当前激活的集合中。地面进场景之后，就可以动手调整了。


默认的几何体太少，置换（displacement）推不出细节，而且贴图比例在这个场景里偏大。接一个 Value 节点到比例（scale）上设为 2，把比例放大一倍。按我的机位角度，我还用映射节点把贴图移了 80mm。再到修改器标签页里把细分修改器级别改成 10，让几何体足够密，撑得起置换图像的细节。


既然用了置换，把地面往下移一点也很有必要：这一个往下移了 7mm。地面现在可以用于渲染了。


环境

记住：HDRI 能提升真实感，但也会影响颜色。拍键盘和场景没问题，但对颜色准确性要求很高的套件渲染就不合适了。要加 HDRI，到 Poly Haven 点 Assets > HDRIs，挑一个下载。这里用 Leadenhall Market，下载下来是 EXR 图像文件。


在大纲视图里停用 Lights 集合。


然后在材质编辑器里点左上角的下拉菜单，从 Object 切到 World。世界材质已经搭好了：选中图像节点按 M 取消静音，再点 Open 载入 Leadenhall Market 图像。


想调整这张图，可以新建 Mapping 节点和 Texture Coordinate 节点，按图里那样连接。这里我把图像转了 52 度，让键盘右侧边缘出现一道好看的高光，同时把 HDRI 强度提高一倍。

KRK 到 3ds Max

导出到 3D Studio Max 相当简单，不过有几件事要先做：3ds Max 处理多边形（N 边形）不如 Blender，但它很喜欢三角形和四边形，所以我们就给它想要的。


键盘或套件准备好后，把不参与导出的其他物体都隐藏起来——通常包括场景集合，把它关掉。


只剩它可见时，选中其中一个物体，按 A 全选，再按 Tab 让所有选中的物体一起进入编辑模式。


需要处在面选择模式，快捷键是数字行的 3。


连按两次 A（或按 Alt+A）取消所有选择。


接着点 Select > Select By Trait > Faces By Sides。


用左下角的弹出面板把类型设为 Greater Than（大于）。


现在所有 N 边形（而且只有 N 边形）都被选中了。


然后点 Face > Triangulate Faces，或按 Ctrl+T 三角化，再按 Tab 退出编辑模式。


键盘现在可以导出了：点 File > Export > FBX，起个文件名，把 Path Mode 设为 Copy，记得勾选 Limit to Selected Objects（仅限选中物体）。


接着在 Max 里导入这个 FBX。


KRK 到 Cinema 4D

导出到 Cinema 4D 很简单。

键盘或套件准备好后，把不想导出的其他物体隐藏或关闭显示。


按键盘上的 A 键全选。


点 File > Export > FBX，起个文件名，别忘了勾选 Limit to Selected Objects（仅限选中物体）。


接着在 Cinema 4D 里导入 FBX，然后点 Tools > Axis > Reset Scale，以及旁边的齿轮图标来应用缩放。


在选项里把两个复选框都勾上。


常见问题（FAQ）


如何安装 Keyboard Render Kit？

Keyboard Render Kit 全部打包在 blend 文件里，用 Blender 打开就能用。


为什么 Blender 提示我要运行脚本？

KRK2 有一部分插件功能，它通过运行一个已注册的脚本实现免安装。


我的键帽去哪儿了？

KRK2 换了新的工作流：场景里先放占位符，再用 KRK 面板把它们换成你选的键帽高度。


我的资产浏览器是空的。

Blender 需要一个配套（sidecar）文件，来指定资产浏览器里显示哪些项目、归入什么分类。压缩包里那个 txt 文件就是它，必须和 blend 文件放在同一个文件夹里。


键盘没有出现在资产浏览器里。

Blender 从 3.2 起才支持集合资产（collection asset），所以请确认版本不低于 Blender 3.2。


我的键帽上没有材质。

KRK2 的键帽模型默认不带材质，这样键帽和 capsmat 才能各自独立更新。

键帽高度

CHE

在 Endeavour 基础上重新建模的 Cherry 高度（圈内俗称「原厂高度」）。底面使用 -2 扩展，使用 Cherry 字符模板，支持侧刻。

DCS

在 Fooblitzky 基础上重新建模的 DCS 高度。底面使用 -2 扩展，使用 DCS 字符模板，支持侧刻。

DSA

从 KRK1 的 DSA 模型衍生而来，用细分修改器把侧面做平滑。

DSS

从 KRK1 的 DSS 模型衍生而来，用细分修改器把侧面做平滑。

KAM

从 KRK1 的 KAM 模型衍生而来，用细分修改器把侧面做平滑。

KAT

从 KRK1 的 KAT 模型衍生而来，用细分修改器把侧面做平滑。

OEM

从 KRK1 的 OEM 模型衍生而来。

SA

从 KRK1 的 SA 模型衍生而来，用细分修改器把侧面做平滑。

额外高度

KRK

KRK1 的键帽模型，含轴体 UI。需要手动导入。

PBS

PBS 高度，带轴心（十字柱）。需要手动导入。

PLA

占位符高度。

SLK

恢复集合实例

Restore Collection Instances（恢复集合实例）是一个小插件，用来补上 Blender 的一个功能缺口：集合资产（collection asset）用 Blender 自带的 “Make Instances Real” 无法正确还原——它能保留父子层级，却保不住原始的集合层级。


下面是开启「保持层级」选项时的 Make Instances Real 与 Restore Collection Instances 的结果对比。

这个例子里，原始集合资产有 176 个物体，其中一部分关闭了可见性。Make Instances Real 只还原了 161 个，而且丢掉了所有集合结构、组织方式和颜色。



Restore Collection Instances 最初只是 Keyboard Render Kit 的一部分，但我们很快发现它可以当通用工具用。



用法很简单：按 Ctrl+A，在 apply（应用）菜单里就能找到它。
