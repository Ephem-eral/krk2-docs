Ваш первый рендер комплекта

Сразу после начала работы вы заметите: в сцене нет кейкапов, только набор плоскостей. Это плейсхолдеры, которые можно заменить на кейкапы.


Выделите рамкой эти плейсхолдеры и нажмите кнопку Set в области Relink (перелинковка) панели KRK. Перелинковка игнорирует все объекты, кроме кейкапов, и теперь вы должны получить кейкапы высоты Cherry; кейкапы без соответствующих данных целевого объекта также будут пропущены. Префиксы высот можно посмотреть в коллекции Profile.


Перетащите Capsmat из браузера ассетов на один из кейкапов, оставьте его активным (подсвеченным) и нажмите кнопку Copy в области Data (данные) панели KRK, чтобы связать материал с остальными кейкапами. Это эквивалентно Ctrl+L и затем M (связать материалы), но игнорирует объекты, не являющиеся кейкапами.


Примечание

Если вы не собираетесь выполнять какую-либо постобработку финального изображения (не рекомендуется), то хотя бы установите схему управления цветом в «Standard» или задайте look в «Medium High Contrast».


Система палитр предназначена для удобного подбора цветов: вы можете сначала настроить цвета для каждого объекта по отдельности, а затем вернуться в редактор шейдеров и использовать заданные палитры для более стандартизированного процесса.


Палитра по сути представляет собой универсальную группу узлов, но по умолчанию настроена следующим образом:

  • A основной цвет кейкапа

  • B цвет легенды

  • C цвет дополнительной легенды (не применён)

  • D цвет легенды на передней грани (не применён)

  • E маска легенды


Подвигайте эти ползунки на кейкапе, переключитесь на custom, чтобы настроить свои цвета. Когда результат вас устроит, оставьте этот кейкап выделенным последним и нажмите Set в области Color (цвет) — настройки применятся ко всем выделенным кейкапам.


Теперь цвета кейкапов можно хранить на объекте, а не только в материале. Если вам привычнее традиционный подход, палитру можно удалить из материала.


С помощью ползунков Palette E можно переключать легенду модификаторов между Text (текст), Icon (иконка) или Text+Icon (текст+иконка).


Включите видимость FloorLightGrey в структуре (Outliner), чтобы добавить пол, он находится первым в Scene > Floors.


Нажмите Render > Render Image или F12, чтобы отрендерить ваше первое изображение.


На этом первый пример рабочего процесса завершён.


Дополнительно: Переключите камеру на Camera_Kit_Tilted в свойствах сцены.
