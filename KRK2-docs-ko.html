Keyboard Render Kit에 오신 것을 환영합니다!

Keyboard Render Kit 2를 사용해 주시고 지원해 주셔서 감사합니다!

KRK2는 KRK1의 오브젝트 데이터 교체 워크플로를 계승하면서 더 유연하고 독립적이며 세분화된 구조로 발전시켰습니다. 키캡 프로파일(높이)은 더 이상 다른 모델의 지오메트리에 의존하지 않으며, 키보드는 자유롭게 이식할 수 있고, 각 구성 요소는 버전과 무관하게 개별적으로 업데이트할 수 있습니다.


실행 요구 사항

Blender 3.3 이상

Blender Cycles를 실행할 수 있는 컴퓨터

관련 링크

Gumroad | BlenderMarket | Instagram | Discord | 레전드 리소스 저장소


빠른 시작

패키지 내용물

다운로드 페이지에서 blend 파일, txt 파일, 그리고 레전드 템플릿(legend template) 관련 SVG 및 기타 소재가 포함된 압축 파일을 받게 됩니다. 같은 폴더에 압축을 풀어 함께 두세요. 이 txt 파일은 Blender 에셋 관리를 위한 사이드카(sidecar) 파일이며, 반드시 blend 파일과 함께 있어야 합니다.


시작하기

KRK2를 시작하는 방법은 초기 KRK와 마찬가지로 간단합니다. Blender(3.3 이상)로 blend 파일을 열면 필요한 모든 것이 파일 안에 들어 있습니다. 파일을 열 때 Blender가 내장 스크립트를 허용할지 묻는 창을 띄웁니다. KRK2 패널은 이 스크립트에 의존해 작동하므로 여기서는 「허용」을 선택하세요.


도움말

커뮤니티에 참여하세요: Discord

관련 자료는 Blender 공식 매뉴얼 에서 확인할 수 있습니다.


인터페이스

KRK2의 인터페이스 레이아웃은 Blender의 「셰이딩」(Shading) 작업 공간과 가장 비슷합니다. 다른 점은 왼쪽 패널이 파일 브라우저와 이미지 에디터 대신 에셋 브라우저와 UV 에디터로 바뀌고, 사이드바에 KRK 탭이 하나 더 추가된다는 것입니다.


에셋 브라우저

에셋 브라우저에는 유형과 제조사별로 분류된 다양한 실용적인 머티리얼이 들어 있습니다.

Blender 매뉴얼: 에셋 브라우저


UV 에디터

이 패널은 이미지 뷰어로도 쓸 수 있고, 키캡의 레전드(키캡 각인) 좌표를 표시할 수도 있습니다.

Blender 매뉴얼: UV 에디터


3D 뷰포트

여기에서 키트, 레이아웃(배열), 조명, 카메라 앵글 등을 편집합니다. 사이드바에는 키캡을 제어하는 KRK 패널이 붙어 있습니다.

Blender 매뉴얼: 3D 뷰포트


셰이더 에디터

여기에서 머티리얼의 외관과 속성을 제어합니다.

Blender 매뉴얼: 셰이더 에디터


아웃라이너

여기에는 blend 파일의 계층 구조가 표시됩니다. 키트, 키보드, 레이아웃(배열), 액세서리, 카메라, 조명, 바닥, 키캡 프로파일(높이) 등이 모두 여기에 있으며, 각 항목의 가시성도 제어할 수 있습니다.

Blender 매뉴얼: 아웃라이너


속성

나머지 속성은 대부분 각 탭에 나누어져 있습니다.

Blender 매뉴얼: 속성 에디터


KRK 패널

KRK 패널은 사이드바(N 키로 열기)에 있으며, Relink, Data, Color, Properties의 네 영역으로 구성됩니다. 마지막 두 영역은 해당 속성을 사용할 수 있을 때만 표시됩니다.


Relink(재링크)

Relink는 오브젝트 데이터 관리자로, 키캡 프로파일(높이), 행, 크기, 키 유형, 위치 키(homing)를 빠르게 전환하는 데 사용합니다. 체크박스로 선택한 옵션은 모두 Set을 누르면 적용됩니다.


KLE 가져오기

KRK는 Keyboard Layout Editor의 JSON 파일을 가져올 수 있습니다. KLE는 오브젝트에 이름을 지정하지 않으므로, 가져오기 기능은 문자와 행(K1-K6)을 기준으로 키를 추론하고, 추론할 수 있는 위치에는 플레이스홀더를 배치합니다. 아래 KLE를 예시로 사용하거나, 이를 바탕으로 자신만의 레이아웃(배열)을 만들 수 있습니다:

http://www.keyboard-layout-editor.com/#/gists/f7528ebe1348daab7abc45bc2f662c8a


Profile(높이)

사용 가능한 높이와 그 접두사는 아웃라이너의 Profile 컬렉션에 있습니다. 행과 기타 옵션은 몇 번 사용해 보면 익숙해집니다. 옵션을 해당 입력 필드에 입력하고(대소문자 구분), 체크박스를 선택한 뒤 Set을 누르면 적용됩니다.


Row(행)

제조사와 키캡 프로파일(높이)마다 사용하는 행 번호 체계가 다르기 때문에, KRK는 키보드상의 실제 위치를 기준으로 마지막 열부터 세는 자체 번호 체계를 도입했습니다.

Size(크기)

입력 필드에 네 자리 크기 단위(unit size)를 입력하면 키캡 크기를 변경할 수 있습니다. 대상 지오메트리가 존재하는 한, 키캡은 원하는 크기로 변합니다.


Key(키)

입력 필드에 키캡 이름을 입력하면 키캡을 다른 키캡으로 교체할 수 있습니다. 레전드 교체형 키캡(Releg), 무각 키캡(Blank), 또는 윈도우 키캡(*_WIN)으로 바꿀 때 특히 편리합니다.


Homing(위치 키)

이 드롭다운 메뉴로 위치 키 유형을 바(bar)/넙(nub)/스쿱(scoop) 사이에서 전환한 뒤 Set을 누릅니다.


Link Material(재질 링크)

Link Material은 현재 적용된 재질을 대상 오브젝트 데이터로 가져옵니다. 켤지 끌지는 원하는 결과에 따라 결정합니다. 예를 들어 플레이스홀더 높이(PLA)로 바꿀 때는 Capsmat도 플레이스홀더로 딸려 가지 않도록 꺼야 합니다.


Copy Settings(설정 복사)

Set 버튼 오른쪽에는 Copy Settings가 있으며, 오브젝트 데이터 이름을 오브젝트 데이터 드롭다운 메뉴로 복사하여 특정 키를 쉽게 찾을 수 있게 해줍니다.


다음 영역은 현재 활성(하이라이트) 오브젝트에 해당하는 옵션만 표시합니다.


Data(데이터)

Data는 속성 패널의 오브젝트 데이터와 재질 할당을 가져와 더 편리하게 접근할 수 있게 해줍니다.


여기서 오브젝트 데이터를 빠르게 검색하여 현재 것을 다른 것으로 바꿀 수 있습니다. 예를 들어 키캡을 복사하거나 인스턴스화한 뒤, 복사본을 스위치나 스태빌라이저로 바꿀 수 있습니다.


키캡이 복사, 가져오기, 또는 붙여넣기로 인해 재링크할 수 없게 되었을 때, Restore Meshes를 사용하면 파일 내 같은 이름의 버전과 다시 연결할 수 있습니다. 가져온 것을 기준으로 삼고 싶다면, 그 오브젝트 데이터의 이름을 바꾸어 끝의 .001을 제거하십시오.


Restore Collections는 컬렉션 에셋을 선택했을 때만 나타나며, 이를 편집 가능한 상태로 복원하는 데 사용합니다.


여기의 Copy는 현재 활성 키캡의 재질을 다른 모든 선택된 키캡에 링크하며, 키캡이 아닌 오브젝트는 무시합니다.


Color(색상)

Color는 색상 및 팔레트 관리 시스템으로, Capsmat의 색상 관련 속성을 제어하는 데 도움을 주며, 색상 속성을 사용할 수 있을 때만 표시됩니다. 선택한 키캡에 색상 속성이 없으면 Setup 버튼이 나타나며, 이 키캡에 필요한 모든 속성을 추가하는 데 사용합니다.


Custom/Palette 토글을 사용하면 사용자 정의 색상과 팔레트의 두 가지 워크플로 사이를 전환할 수 있습니다. 색상 A-E와 팔레트 슬라이더 A-E는 팔레트 노드 그룹을 통해 Capsmat의 해당 부분을 오브젝트별로 제어할 수 있게 해줍니다. 선택 후 Set을 누르면 모든 선택된 키캡에 적용되며, 각각의 복사 버튼을 눌러 한 번에 하나씩만 복사할 수도 있습니다. 하단의 Copy와 Paste는 모든 선택된 오브젝트에 대한 옵션 기록을 만들고 불러오는 데 사용합니다.


Properties(속성)

Properties 역시 사용자 정의 속성을 사용할 수 있을 때만 표시됩니다. USB 케이블을 선택하면 브레이드/TechFlex와 커넥터 열수축 튜브의 색상 같은 케이블 옵션이 표시되고, 데스크매트를 선택하면 크기와 스티치 옵션이 표시됩니다.

키보드 모델은 Boards(키보드) 카테고리에 있습니다.

머티리얼 에셋

에셋 브라우저에는 다양한 실용 머티리얼이 미리 설정되어 있으며, 유형과 제조사별로 분류되어 있어 뷰포트의 오브젝트에 바로 드래그할 수 있습니다.


머티리얼 도구

직접 머티리얼을 만들 때는 이 도구들을 셰이더 에디터로 드래그하여 효과를 추가할 수 있습니다.


UV 에디터

UV 에디터는 이미지 뷰어이자 UV 좌표 에디터입니다. 2D 이미지가 3D 공간에 매핑되었을 때 어떻게 보이는지 직관적으로 확인할 수 있습니다.


Blender의 UV 좌표에 대해 더 자세히 알아보려면 Blender 매뉴얼: UV 설명 을 참고하세요.


셰이더 에디터

오브젝트를 선택하면 해당 오브젝트에 적용된 머티리얼을 머티리얼 에디터에서 편집할 수 있으며, 이는 현재 활성화(하이라이트)된 오브젝트에만 적용됩니다.


드롭다운 메뉴를 사용하면 오브젝트의 머티리얼을 다른 것으로 바꿀 수 있습니다.


특정 머티리얼을 독립시키고, 이를 수정할 때 다른 오브젝트에 영향을 주지 않으려면 이름 옆의 숫자(이 머티리얼을 사용하는 오브젝트 수를 나타냄)를 클릭하면 됩니다. 한 번 클릭하면 새로운 머티리얼 복사본이 생성됩니다. 「새 머티리얼」 버튼을 클릭해도 같은 효과를 얻을 수 있습니다.


이미지 텍스처 노드는 좌표가 있어야 2D 이미지를 3D 오브젝트에 어떻게 매핑할지 결정할 수 있습니다. 벡터(Vector) 입력에 아무 좌표도 연결되지 않으면, 현재 활성화된 UV가 사용됩니다.

일부 머티리얼에는 음소거된 노드(회색으로 표시됨)가 포함되어 있으며, 렌더링 시 계산에 참여하지 않습니다. 활성화하려면 해당 노드를 좌클릭으로 선택하고 M을 눌러 음소거를 해제하면 됩니다.


월드 머티리얼도 셰이더 에디터에서 편집할 수 있습니다. 왼쪽 상단에 Object로 표시된 드롭다운 메뉴를 클릭하여 World로 변경하세요.


아웃라이너

아웃라이너는 씬의 모든 항목을 정리하고 컬렉션으로 구성합니다.

키트

Kits(키트) 컬렉션은 기본적으로 켜져 있습니다.

키보드

키보드는 먼저 크기별로 그룹화되고, 같은 크기 안에서는 알파벳순으로 정렬됩니다. 삼각형 화살표를 클릭하면 하위 컬렉션을 단계별로 펼칠 수 있으며, 그 아래에는 단차 캡스락이나 Tsangan 하단열 같은 키보드의 레이아웃(배열) 옵션이 있습니다.

레이아웃(배열)

이들은 직접 가져온 키보드를 채우는 데 사용할 수 있는 대체 레이아웃(배열)입니다. 레이아웃(배열)을 마우스 오른쪽 버튼으로 클릭하고 「연결 복제」를 선택해 연결 컬렉션을 생성한 다음, 자신의 키보드가 속한 컬렉션으로 옮기면 됩니다.

액세서리

데스크매트 모델, 마우스, USB 케이블, 손목 받침대 등 사용 가능한 액세서리가 나열됩니다.

씬

여기에서 조명, 카메라, 배경 등 씬 요소에 접근할 수 있습니다.

카메라

KRK2는 카메라를 간소화했지만, 복제하여 카메라 위치와 각도를 직접 설정할 수 있습니다.

조명

씬의 전체적인 느낌을 정할 수 있도록 여러 조명 프리셋을 준비했습니다. 인기 있는 스튜디오 조명 HDRI 프리셋을 참고했으며, 조정 가능성이 더 높아 강도와 위치를 자유롭게 조절할 수 있습니다.

바닥

KRK에는 빠르게 시작할 수 있도록 흥미로운 바닥 세트가 포함되어 있습니다. 여기에는 섀도 캐처(ShadowCatcher) 바닥이 포함되며, 이는 FloorLightGrey를 기반으로 하여 그림자를 전문적으로 포착해 투명 배경 렌더링에 사용됩니다.

구조

키캡 프로파일(높이)

모든 키캡 프로파일(높이)이 여기에 있습니다.

UV 설정

이 컬렉션에는 키캡의 UV 투영에 필요한 모든 내용이 포함되어 있습니다.

부품

여기에는 오브젝트 데이터 교체를 통해 자신의 키보드에 추가할 수 있는 몇 가지 추가 부품이 포함되어 있습니다.

속성 에디터

Blender의 속성 패널은 다룰 내용이 매우 많으므로, 여기서는 가장 관련 있는 몇 가지 부분만 살펴봅니다.


렌더 속성

렌더 장치

GPU(그래픽 카드)로 렌더링을 가속할 수 있습니다. 주의: 환경 설정에서 컴퓨팅 장치를 설정해야 적용됩니다.

샘플 수

뷰포트 기본 샘플 수는 32, 최종 렌더링은 256입니다. 폴리카보네이트(PC) 재질을 렌더링하려면 최소 512 이상으로 설정할 것을 강력히 권장합니다.

노이즈 제거

노이즈 제거는 여기서 설정합니다. 저는 보통 뷰포트 노이즈 제거를 켜고 자동으로 설정하며, 시작 샘플 수를 2 이상으로 두어 뷰포트가 부드럽게 유지되도록 합니다. 최종 렌더링의 노이즈 제거는 컴포지터에서도 할 수 있습니다.

필름 투명

투명 배경 이미지를 렌더링하려면 Film(필름) > Transparent(투명)를 켜야 합니다.

색 관리

이 섹션은 중요합니다. Blender 색 관리 기본값은 Filmic이며, 저도 여기서 기본값을 유지하고 look을 적용하지 않습니다. 일부 사용자는 색상 맞추기가 더 쉽다고 느껴 Standard로 설정하는 것을 선호합니다. 저는 개인적으로 Filmic을 더 선호합니다: 하이라이트 전환이 더 부드럽고, Medium High Contrast와 함께 사용하면 느낌이 Standard에 매우 가깝지만 명암 단계가 더 좋습니다. EXR로 내보낼 계획이라면 여기 옵션은 상관없습니다 — EXR은 전체 버퍼 데이터를 그대로 내보냅니다.


출력 속성

해상도

여기서 출력 이미지의 해상도를 설정합니다. UV 프로젝션 같은 작업을 할 때 해상도 역시 결과에 영향을 줍니다.


팁: 현재 2K인데 4K로 설정하고 싶다면, 입력란에 100% 대신 200%를 직접 입력하면 됩니다.


씬 속성

활성 카메라

여기서 렌더링 시 Blender가 어느 카메라를 사용할지 설정합니다.


오브젝트 데이터 속성

오브젝트 데이터

Object Data(오브젝트 데이터) 드롭다운 메뉴를 건너뛰지 마세요: 항목을 선택하면 임의의 오브젝트를 다른 종류의 오브젝트로 바꿀 수 있습니다.

UV 맵

특정 오브젝트의 UV 맵에 접근해야 할 때 여기서 찾으면 됩니다.


재질 속성

재질 인덱스

하나의 오브젝트에 여러 재질을 넣을 수 있습니다. 예를 들어 개방형 키캡과 레전드 교체형 키캡에는 두 개의 재질 슬롯이 있습니다: 하나는 키캡 재질, 하나는 폴리카보네이트(PC)입니다.

재질 링크

오브젝트 데이터의 재질을 사용할지, 오브젝트 자체의 재질을 사용할지 오브젝트별로 Blender에 지정할 수 있습니다.


색 관리

Blender의 색 관리는 선형 색 공간을 기반으로 하며, 뷰 트랜스폼의 기본값은 AGX(4.0 이전은 Filmic)입니다. 이러한 뷰 트랜스폼은 매우 넓은 다이내믹 레인지를 수용할 수 있지만, 후처리를 하지 않으면 선택한 색상이 회색빛으로 보이고 대비가 낮아집니다.


이 워크플로의 전제는 후처리를 통해 색상을 실제에 더 가깝게 조정하겠다는 것입니다. 이를 원하는 사람은 많지 않으므로(특히 신규 사용자), KRK 211부터 KRK는 기본적으로 Filmic + Medium High Contrast를 사용하고, 이후 (컴포지터)에서 Filmic을 sRGB로 변환하여 더 기대에 맞는 결과를 얻습니다.


뷰포트는 이미 설정되어 있으므로, 보이는 모든 내용은 컴포지터를 거쳐 처리됩니다. 새 3D 뷰포트를 만들 경우, 색상이 올바르게 복원되도록 합성(compositing)을 Always로 설정해야 합니다.


최종 판단은 항상 눈으로 하십시오. 항상 실물 참고 자료와 비교하십시오.

Capsmat(키캡 재질)

설정 항목

Cap(키캡 바탕색)

키캡의 바탕색입니다. 색상 필드에서 직접 조정하거나, 팔레트를 연결해 제어할 수 있습니다.

Legend(레전드)

레전드의 색상입니다. 단일 색상을 고르거나 팔레트로 제어할 수 있으며, 이미지를 슬롯에 연결해 풀컬러 레전드를 만들 수도 있습니다.

Legend Mask(레전드 마스크)

검은 바탕에 흰 글자 이미지를 연결해, 키캡 바탕색과 레전드 색상 사이를 블렌딩하는 데 사용합니다.

Sharpen Legend(레전드 샤픈)

레전드 가장자리를 샤픈해 이색 성형(doubleshot) 레전드 효과를 만듭니다. 기본값은 최대로 설정되어 있으며, 0까지 내려 승화 인쇄(dye sublimation)에 가까운 느낌을 낼 수 있습니다.

Legend Weight(레전드 굵기)

레전드 샤픈의 원리상, 이 값을 이용해 레전드를 굵게 만들 수도 있습니다. 값이 작을수록 레전드가 굵어집니다.

Sub(서브 레전드)

서브 레전드의 색상입니다.

SubMask(서브 레전드 마스크)

서브 레전드 파일을 연결하는 슬롯입니다.

Sharpen Sub(서브 레전드 샤픈)

레전드 샤픈과 동일하지만 서브 레전드에 적용됩니다.

Sub Weight(서브 레전드 굵기)

레전드 굵기와 동일하지만 서브 레전드에 적용됩니다.

Front(측면 레전드)

측면 레전드의 색상입니다.

Front Mask(측면 레전드 마스크)

측면 레전드 마스크의 슬롯입니다.

Shapen Front(측면 레전드 샤픈)

레전드 샤픈과 동일하지만 측면 레전드에 적용됩니다.

Front Weight(측면 레전드 굵기)

레전드 굵기와 동일하지만 측면 레전드에 적용됩니다.

Roughness(러프니스)

키캡 재질 전체의 러프니스(즉 광택감)입니다. 구체적인 값은 원하는 플라스틱이나 표면 처리에 따라 달라지며, 예를 들어 PBT는 일반적으로 ABS보다 거칠습니다.

Bump Scale(범프 비율)

범프 노이즈의 스케일(즉 입자 크기)입니다. 사포의 입자 수로 이해하면 됩니다. 값이 클수록 입자가 촘촘해집니다.

Top Bump(상단 범프)

키캡 상단 범프의 강도입니다.

Side Bump(측면 범프)

키캡 뒷면, 앞면, 좌우 측면 범프의 강도입니다.

Legend Seam(레전드 이음새)

일부 이색 성형 공정에서는 레전드와 키캡 사이에 더 뚜렷한 이음새가 남습니다.


마스크

마스크는 검은 바탕에 흰 글자로 된 이미지로, 두 색상 또는 두 요소가 어떻게 블렌딩되는지 정의합니다. 흰색은 「켜짐」, 검은색은 「꺼짐」으로 이해하면 됩니다.


Capsmat에서 마스크는 키캡 바탕색을 레전드, 서브 레전드, 측면 레전드와 각각 블렌딩하는 데 사용됩니다. 어느 하나라도 없으면 해당 부분은 검은색(꺼짐)으로 처리됩니다.


KRK에는 이러한 마스크를 훨씬 쉽게 만들 수 있는 템플릿이 포함되어 있습니다.


팔레트 워크플로

KRK2는 배색을 탐색하고 디자인할 수 있도록 새로운 워크플로를 도입했습니다. 앞서 보았듯이 KRK 패널에서는 키캡의 색상을 개별적으로 제어할 수 있습니다. 먼저 각 키캡에 개별적으로 색을 지정한 다음, 그 색상들을 팔레트로 드래그해 자신만의 배색 체계를 정의할 수 있습니다. 팔레트 노드 그룹은 이 워크플로의 또 다른 부분입니다.

팔레트는 A부터 E까지 있으며, 별도로 셰이더 에디터에서 색상을 구동하는 독립 팔레트가 하나 있습니다. 각 팔레트에는 8개의 색상 슬롯이 있고, Palette E는 4개의 색상 슬롯과 4개의 알파 슬롯으로 구성됩니다.


Inkscape

레전드 파일은 Inkscape에서 제작하며, 무료로 내려받을 수 있습니다:

Inkscape

앞으로는 각 높이마다 개별 템플릿이 제공됩니다. KRK1은 모든 높이를 하나의 파일에 담았지만, 새로 모델링한 키캡은 UV 공간이 달라서 이제는 각각 독립된 템플릿으로 분리되었습니다.

이 복사본 컬렉션을 우클릭하고 “select objects”(오브젝트 선택)를 선택합니다. 그중 하나가 활성(하이라이트) 상태인지 확인하고, 아니라면 3D 뷰에서 Shift를 누른 채 좌클릭하여 활성으로 설정합니다. 그런 다음 오브젝트 데이터 드롭다운 메뉴에서 “switch”를 입력하고, 필요에 따라 Switch_Simple 또는 Switch_Complex를 선택합니다.


이제 하나가 스위치로 변환되었습니다. Ctrl+L을 눌러 Link(연결) 메뉴를 열고, O를 눌러 Object Data(오브젝트 데이터)를 선택하면 나머지 오브젝트도 모두 스위치로 변환되어, 키보드 전체의 스위치를 얻게 됩니다.


다음으로 스태빌라이저를 추가합니다. 스태빌라이저가 필요한 스위치 하나를 선택하고, Alt+D로 연결 복제한 다음 우클릭하거나 Esc를 눌러 이동을 취소합니다.


새 스위치가 선택된 상태에서 Object Data(오브젝트 데이터) 드롭다운 메뉴를 열고, “stab”을 입력하여 스태빌라이저를 필터링한 다음, 필요에 따라 단순 또는 복잡한 모델, 그리고 스태빌라이저의 크기와 방향을 선택합니다.


나머지 스태빌라이저도 같은 방식으로 처리하면 완료됩니다.


커스텀 키보드 준비

이 튜토리얼은 사용하는 CAD 소프트웨어의 내보내기 설정을 다루지 않습니다. 먼저 디자인을 OBJ 또는 FBX로 내보낸 다음 Blender로 가져오세요. 다른 방법으로는 Stepper라는 Blender 애드온을 사용해 STEP/STP 파일을 직접 가져올 수 있습니다.


여기서는 Alchemist Keyboards Aella의 렌더링 파일을 OBJ로 변환한 것을 예로 사용합니다. 오른쪽 클릭 후 다른 이름으로 저장


새 Blender 파일을 만들고 A X D를 눌러 기본 오브젝트(큐브, 카메라, 라이트)를 삭제한 다음, 속성 패널의 Scene Properties 탭에서 단위를 밀리미터(millimeters)로 설정합니다.


이제 Aella의 OBJ를 가져옵니다. File > Import > Wavefront Obj(F4 I W)를 클릭합니다.


바로 비율이 맞지 않는 것을 확인할 수 있습니다. 여기서는 밀리미터 단위가 미터로 가져와졌습니다.


S 0.001을 눌러 키보드를 1000분의 1로 축소합니다. 축소 후에는 보이지 않을 수 있으니 Home 키를 눌러 뷰를 다시 프레이밍합니다.


이제 스케일과 회전을 적용합니다. Ctrl+A를 누르고 다시 A를 눌러 All Transforms(모든 변환 적용)를 선택합니다.


다음으로 이동 핸들을 만듭니다. Add > Mesh > Plane(Shift+A M P)을 선택합니다.


Shift를 누른 채 키보드 하판을 클릭해 선택에 추가한 다음, Object > Transform > Align Objects로 평면을 정렬합니다. 대화 상자에서 Shift를 누른 채 X와 Y 두 축을 클릭합니다.


Align Objects를 한 번 더 반복합니다. 이번에는 Align Mode를 Negative Sides(음의 방향 면)로 설정하고 축은 Z를 선택합니다.


평면 위치가 올바르게 되었으면 키보드 하판보다 약간 크게 축소하고(S X, 그다음 S Y), 스케일을 적용합니다.


Object > Convert > Curve로 곡선으로 변환합니다. 이동 핸들이 완성되었습니다.


키보드의 모든 오브젝트를 이 이동 핸들에 부모 지정합니다. 이동 핸들을 선택한 상태로 유지하고 A를 눌러 전체 선택한 다음 Ctrl+P > Object (Keep Transform)을 선택합니다. 이렇게 하면 이후 이동 핸들을 움직일 때 나머지 부분도 함께 따라 움직입니다. Alt+G를 눌러 위치를 초기화하고 이동 핸들과 모든 자식 오브젝트를 월드 원점으로 재설정합니다.


이제 키캡 레이아웃을 가져옵니다. 여기서는 75% 레이아웃을 사용합니다. File > Append를 클릭하고 KRK201 파일을 찾아 더블 클릭해 엽니다(blend 파일은 폴더처럼 동작합니다). Collections로 들어가 75를 검색하고 75 컬렉션을 추가합니다.


해당 컬렉션의 뷰포트 가시성을 켜야 할 수도 있습니다. 아웃라이너에서 뷰포트 비활성화 필터(viewport disable filter)를 열고 75 컬렉션을 체크합니다.


레이아웃에 포함된 이동 핸들(십자 모양의 빈 오브젝트)을 선택하고, 주 키 영역(Alphas)을 참조해 레이아웃을 적절한 위치로 이동한 다음 X축으로 7도 회전합니다(이것이 Aella의 경사각입니다).


레이아웃의 이동 핸들을 키보드의 이동 핸들에 부모 지정합니다.


플레이스홀더는 하나씩 이동해야 키보드 레이아웃과 정렬됩니다. 그리드 크기(grid size)에 0.002381을 입력하면 스냅 증분을 1/8 단위로 설정할 수 있습니다.


Tsangan 하단열을 엽니다.


이동할 플레이스홀더를 선택하고 축 제약으로 이동합니다. G X는 X축, G YY는 로컬 Y축, 이런 식입니다. Win 키는 삭제하고, Alt 키는 왼쪽 키를 연결 복제해 가져옵니다(Ctrl+L 후 O). Ctrl을 누르거나 자석 아이콘을 클릭해 스냅을 켜면 스냅 증분을 사용할 수 있습니다.


이제 키보드가 준비되었고 KRK2와도 호환됩니다. 배포용으로 압축 blend 파일로 저장한 다음 KRK2로 가져오면 됩니다.


KLE에서 KRK로

Keyboard Layout Editor는 오브젝트에 이름을 지정하지 않지만, 이름 지정은 Blender와 Keyboard Render Kit이 정상적으로 작동하기 위한 필수 조건입니다. Blender는 오브젝트와 오브젝트 데이터에 각각 이름을 지정합니다. Keyboard Render Kit은 기본적으로 오브젝트 이름은 보지 않지만, 오브젝트 데이터 이름에 크게 의존하여 작동합니다. 이 점만 이해하면 KLE에서 KRK로의 변환은 상당히 안정적입니다.


무엇을 KRK로 변환할 수 있을까요? 변환기는 크기, 레전드, 행(row), 색상(키캡 색상과 레전드 색상), 위치 및 회전을 처리합니다. 뒤의 세 가지는 마음대로 변경할 수 있지만, 앞의 세 가지를 변경하면서 대응하는 대상 오브젝트 데이터가 없으면 키캡이 임포트되지 않을 수 있습니다.


Keyboard Layout Editor 예시


이 배열은 KLE에서 KRK로의 변환 테스트 기준이며, KRK에 순조롭게 로드되므로 좋은 참고 샘플입니다. 아직 자신만의 배열을 만들지 않았다면 여기서 시작하는 것이 적합합니다. 어딘가 익숙해 보일 수 있습니다 — KRK에서 키캡의 UV와 텍스처에 사용하는 배열이 바로 이것입니다.



레전드와 행의 이름 지정에 주의하세요. 변환 시 실제로 작동하는 것이 바로 이것들이기 때문입니다. 이를 변경하면 전혀 변환되지 않을 수 있습니다. 레전드 자체는 변환되지 않으며, 단지 키캡의 이름 역할을 한다는 점을 기억하세요 — Blender로 들어간 후에는 레전드 마스크를 통해 키캡에 임의의 레전드를 표시할 수 있습니다.

렌더링 최적화

씬 복잡도 외에도 렌더링 시간과 화질에 영향을 주는 주요 요인이 몇 가지 있습니다.


해상도

해상도는 렌더링 소요 시간에 큰 영향을 줍니다. 너무 낮으면 화면에 픽셀 블록이 생기고, 대각선에 계단 현상이 나타나며, 디테일도 마땅히 가져야 할 선명도를 잃습니다.

예를 들어: 백분율 슬라이더를 200%로 설정하면 해상도가 2K에서 4K로 두 배가 됩니다. 화질은 확실히 더 정교해지지만, 컴퓨터가 처리해야 할 픽셀 수는 네 배가 됩니다. 더 선명한 이미지를 얻는 대신 렌더링 시간이 크게 늘어납니다.


샘플 수

샘플 수도 렌더링 최적화의 핵심입니다. 샘플 수가 너무 적으면 화면에 노이즈가 생깁니다. 해상도와 마찬가지로 샘플 수를 높이면 화질이 개선되지만, 렌더링 시간이 기하급수적으로 증가합니다.


노이즈 제거

디지털 이미지가 등장한 이래로 노이즈 제거에 대한 수요도 함께 있었습니다. 소재가 디지털 사진이든, 스캔본이든, 완전히 컴퓨터로 생성한 것이든 처리 방법은 통용됩니다. 최근에는 패스 트레이싱 렌더링이 새로운 알고리즘의 발전을 이끌었고, 심지어 머신 러닝으로 해결하기 시작했습니다. Blender는 몇 가지 노이즈 제거 알고리즘을 제공하는데, 아래 두 가지를 중점적으로 살펴보겠습니다.

Optix

Nvidia의 머신 러닝 노이즈 제거 알고리즘으로, RTX 20 시리즈 이후의 Nvidia 그래픽 카드에서 실행할 수 있습니다. 전용 텐서 코어를 사용하기 때문에 속도가 매우 빠르지만, Nvidia 사용자로 제한됩니다. 더 많은 정보는 NVIDIA 공식 페이지 를 참조하세요.

Open Image Denoise

Intel에서 만든 또 다른 머신 러닝 노이즈 제거 알고리즘입니다. 이름에서 알 수 있듯이 오픈 소스이며, 다양한 CPU 모델과 아키텍처에서 실행할 수 있습니다. 속도는 Optix보다 느리지만 효과가 매우 뛰어나며, 투명도가 있는 씬, 예를 들어 폴리카보네이트(PC) 키보드를 렌더링할 때 더 유리합니다. Open Image Denoise에 대한 더 많은 정보는 공식 사이트 를 참조하세요.

실제 적용

두 알고리즘 모두 옵션에서 활성화하여 뷰포트와 최종 렌더링에 사용할 수 있습니다. 다만 컴포지터에서 사용할 때는 Open Image Denoise가 더 빠릅니다. KRK는 이미 컴포지터 노드를 구성해 두었으므로, 컴포지터 패널 왼쪽 상단의 체크박스로 활성화하기만 하면 됩니다.


노이즈 제거를 더 깊이 이해하려면 Blender 매뉴얼: 노이즈 줄이기 를 참조하세요.


Poly Haven 에셋

키보드가 준비되었고, 키캡 프로파일과 색상도 정했으며, 카메라 구도도 괜찮지만 조명과 바닥이 원하는 대로 나오지 않습니다.


KRK에는 시작할 수 있는 다양한 바닥과 조명 프리셋이 있지만, 다른 바닥과 조명으로 바꿔서 화면을 더 풍부하게 만들고 싶을 수 있습니다. Poly Haven은 키보드를 올려둘 표면과 씬을 비출 HDRI(하이 다이내믹 레인지 이미지)를 모두 제공하는 훌륭한 리소스 사이트입니다. 아래에서 가져오는 과정을 살펴보겠습니다.


Poly Haven 애드온이 이미 설치되어 있다면 이 과정 대부분을 건너뛸 수 있습니다. 자주 사용한다면 설치를 강력히 추천합니다.


바닥

먼저 Poly Haven 웹사이트(polyhaven.com)에 접속해 상단 바에서 Assets > Textures를 클릭합니다.


여러 카테고리가 있는데, 여기서는 Floor > Indoor > Man-Made를 클릭한 다음 Slab Tiles를 선택합니다.


다운로드 버튼을 클릭하고 zip 다운로드가 끝나면 해당 폴더에 압축을 풉니다. 폴더 안에 blend 파일이 있으면 이미 구성되어 바로 사용할 수 있는 오브젝트가 들어 있다는 뜻입니다.


blend 파일의 내용을 가져오려면 Append 또는 Link를 사용해야 합니다. 여기서는 바닥을 append하고 원본 파일과 링크를 유지하지 않습니다. Blender에서 File > Append를 클릭해 Poly Haven 바닥 가져오기를 시작한 다음, Object 하위 분류를 선택하고 바닥 오브젝트를 찾습니다. 이름은 아마 “Plane”일 것입니다.


오브젝트는 아웃라이너에서 현재 활성화된 컬렉션에 추가됩니다. 바닥이 씬에 들어왔으니 이제 조정할 수 있습니다.


기본 지오메트리가 너무 적어서 디스플레이스먼트로 디테일을 밀어낼 수 없고, 텍스처 비율도 이 씬에서는 너무 큽니다. Value 노드를 스케일(scale)에 연결해 2로 설정하면 비율이 두 배로 커집니다. 제 카메라 각도에서는 매핑 노드로 텍스처를 80mm 이동했습니다. 그런 다음 모디파이어 탭에서 세분화 모디파이어 레벨을 10으로 변경해 지오메트리를 충분히 촘촘하게 만들어 디스플레이스먼트 이미지의 디테일을 받쳐줍니다.


디스플레이스먼트를 사용했으니 바닥을 조금 아래로 옮기는 것도 필요합니다. 이 경우 7mm 내렸습니다. 이제 바닥을 렌더링에 사용할 수 있습니다.


환경

기억하세요: HDRI는 사실감을 높여주지만 색상에도 영향을 줍니다. 키보드와 씬 촬영에는 문제없지만, 색 정확도가 매우 중요한 키트 렌더링에는 적합하지 않습니다. HDRI를 추가하려면 Poly Haven에서 Assets > HDRIs를 클릭하고 하나를 골라 다운로드합니다. 여기서는 Leadenhall Market을 사용하며, 다운로드하면 EXR 이미지 파일입니다.


아웃라이너에서 Lights 컬렉션을 비활성화합니다.


그런 다음 셰이더 에디터에서 왼쪽 상단 드롭다운 메뉴를 클릭해 Object에서 World로 전환합니다. 월드 머티리얼이 이미 구성되어 있습니다. 이미지 노드를 선택하고 M을 눌러 음소거를 해제한 다음, Open을 클릭해 Leadenhall Market 이미지를 불러옵니다.


이 이미지를 조정하려면 Mapping 노드와 Texture Coordinate 노드를 새로 만들고 그림처럼 연결합니다. 여기서는 이미지를 52도 회전해 키보드 오른쪽 가장자리에 멋진 하이라이트가 나타나게 했고, HDRI 강도를 두 배로 높였습니다.

KRK에서 3ds Max로

3D Studio Max로 내보내는 것은 상당히 간단하지만, 먼저 해야 할 일이 몇 가지 있습니다. 3ds Max는 Blender만큼 다각형(N각형)을 잘 처리하지 못하지만, 삼각형과 사각형은 아주 좋아하므로 원하는 대로 만들어 줍시다.


키보드나 키트가 준비되면 내보내기에 포함되지 않을 다른 오브젝트를 모두 숨깁니다. 보통 씬 컬렉션이 여기에 해당하므로 꺼 둡니다.


이것만 보이게 되면 그중 하나의 오브젝트를 선택하고 A를 눌러 전체 선택한 뒤, Tab을 눌러 선택된 모든 오브젝트를 함께 편집 모드로 전환합니다.


면 선택 모드에 있어야 하며, 단축키는 숫자 행의 3입니다.


A를 두 번 연속 누르거나(또는 Alt+A) 모든 선택을 해제합니다.


이어서 Select > Select By Trait > Faces By Sides를 클릭합니다.


왼쪽 아래의 팝업 패널에서 유형을 Greater Than(초과)으로 설정합니다.


이제 모든 N각형(그리고 N각형만)이 선택되었습니다.


그런 다음 Face > Triangulate Faces를 클릭하거나 Ctrl+T로 삼각화하고, Tab을 눌러 편집 모드를 종료합니다.


이제 키보드를 내보낼 수 있습니다. File > Export > FBX를 클릭하고 파일 이름을 지정한 뒤, Path Mode를 Copy로 설정하고 Limit to Selected Objects(선택한 오브젝트만)를 반드시 체크합니다.

KRK에서 Cinema 4D로 내보내기

Cinema 4D로 내보내는 방법은 간단합니다.

키보드나 키트가 준비되면, 내보내지 않을 다른 오브젝트는 숨기거나 표시를 꺼둡니다.


키보드에서 A 키를 눌러 전체를 선택합니다.


File > Export > FBX를 클릭하고 파일 이름을 지정한 뒤, Limit to Selected Objects(선택한 오브젝트만)를 체크하는 것을 잊지 마세요.


그다음 Cinema 4D에서 FBX를 임포트한 후, Tools > Axis > Reset Scale을 클릭하고 옆의 톱니바퀴 아이콘을 눌러 스케일을 적용합니다.


옵션에서 두 체크박스를 모두 체크합니다.


자주 묻는 질문(FAQ)


Keyboard Render Kit은 어떻게 설치하나요?

Keyboard Render Kit은 모든 내용이 blend 파일에 들어 있으므로 Blender로 열면 바로 사용할 수 있습니다.


Blender가 스크립트를 실행하라고 하는 이유는 무엇인가요?

KRK2는 일부 애드온 기능을 포함하고 있으며, 등록된 스크립트를 실행하는 방식으로 별도 설치 없이 동작합니다.


제 키캡은 어디로 갔나요?

KRK2는 새로운 워크플로를 사용합니다. 씬에 먼저 플레이스홀더를 배치한 다음, KRK 패널에서 원하는 키캡 프로파일(높이)로 교체합니다.


제 에셋 브라우저가 비어 있습니다.

Blender는 에셋 브라우저에 어떤 항목을 표시하고 어떤 분류로 묶을지 지정하는 사이드카(sidecar) 파일이 필요합니다. 압축 파일 안의 txt 파일이 바로 그것이며, blend 파일과 같은 폴더에 있어야 합니다.


키보드가 에셋 브라우저에 나타나지 않습니다.

Blender는 3.2부터 컬렉션 에셋(collection asset)을 지원하므로, Blender 버전이 3.2 이상인지 확인하세요.


제 키캡에 머티리얼이 없습니다.

KRK2의 키캡 모델은 기본적으로 머티리얼이 없으며, 이렇게 해야 키캡과 capsmat을 각각 독립적으로 업데이트할 수 있습니다.

컬렉션 인스턴스 복원

Restore Collection Instances(컬렉션 인스턴스 복원)는 Blender의 기능 공백을 메우는 작은 애드온입니다. 컬렉션 에셋은 Blender 기본 제공 “Make Instances Real”로는 제대로 복원할 수 없습니다. 부모-자식 계층은 유지되지만 원래의 컬렉션 계층은 보존되지 않습니다.


아래는 「계층 유지」 옵션을 켰을 때의 Make Instances Real과 Restore Collection Instances의 결과 비교입니다.

이 예시에서 원본 컬렉션 에셋에는 176개의 오브젝트가 있으며, 그중 일부는 가시성이 꺼져 있습니다. Make Instances Real은 161개만 복원했고, 모든 컬렉션 구조와 구성 방식, 색상까지 잃어버렸습니다.



Restore Collection Instances는 처음에는 Keyboard Render Kit의 일부였지만, 곧 범용 도구로 쓸 수 있다는 것을 알게 되었습니다.



사용법은 간단합니다. Ctrl+A를 누르면 Apply(적용) 메뉴에서 찾을 수 있습니다.
